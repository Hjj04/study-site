第一部分 课程讲解

0. 整体知识脉络

这门课前面几讲已经讲了：

  • L1–L3：网络的例子与度量指标（degree、path、clustering 等）
  • L4–L6：节点群组（community 等）
  • L7–L10：随机网络模型（ER、配置模型等）

从 L13 开始进入一个新主题：分析真实世界的网络与过程。 现实中的网络往往不像随机图那样自由——它们要么嵌入在空间中（道路、铁路、航线）， 要么随时间演化（电话联系、社交互动），或两者兼具。 因此，我们需要一套专门的度量、可视化方法和模型来研究它们。

把它想象成"地图 + 时刻表"：之前的网络像是一张抽象关系图，现在我们要在它上面叠加 GPS 坐标（空间）和时间戳（时间）。 这两件事一旦加入，许多原本随心所欲的连接就受到了"距离成本"和"先后顺序"的约束。

本讲将解决的四个核心问题

  1. 什么是空间网络 / 时间网络？
  2. 用什么指标分析它们？
  3. 有哪些空间模型可供比较？
  4. 怎样为真实系统构建空间 / 时间网络模型？

1. 空间网络 (Spatial Networks)

空间网络是指满足以下两个条件的网络：
  • 节点和边都有空间位置
  • 网络结构受空间影响或约束
通常，连接两个节点会有一个"代价"，与它们之间的距离有关。

典型例子：道路网、铁路网、航线网、真菌根系。

反思：是不是所有网络都是空间网络？

看似如此，但不是。是否把网络建模为"空间网络"，取决于研究问题是否真的关心距离。

朋友关系网：现实中朋友常常住得近——但理论上你也可以有地球另一端的朋友。 如果你研究"距离对友谊建立的影响"，可以用空间网络；否则空间技术对友谊网就没什么意义。 空间网络的工具，主要为空间约束严格的网络（如道路）而设计。

2. 平面网络 (Planar Networks)

平面网络：可以画在平面上，使所有边互不相交的网络。
注意关键词是 "can be drawn"——只要存在一种不交叉画法即可，不要求初始画法不交叉。
左/中：平面（可不交叉画）；右：K₅，无论如何画都会有边相交

2.1 Kuratowski 定理

网络是非平面的，当且仅当它包含 $K_5$（5 节点完全图）或 $K_{3,3}$（3+3 节点完全二部图）作为子网络。

2.2 真实世界的平面网络

几乎没有完全平面的真实网络：飞机航线显然不平面；公路有立交桥技术上也不平面。 但在很多应用中，路网可以近似为平面网络。

2.3 欧拉公式 (Euler's Formula)

设 $n$ = 节点数，$m$ = 边数，$f$ = 面数（被边围成的平面区域，包括外部那个"无界面"）。则： $$n - m + f = 2$$ 若不计外部面 $f^* = f - 1$，则： $$n - m + f^* = 1$$
证明思路（伸缩到生成树）：令 $N = n - m + f$。 每去掉一条形成环路的边，$m$ 和 $f$ 都减 1，所以 $N$ 不变。 一直去到只剩一棵生成树：$f = 1$，$m = n - 1$，于是 $N = n - (n-1) + 1 = 2$。 把边一条条加回来，$N$ 始终是 2。

2.4 平面图平均度的上界

平面图的平均度满足： $$\langle k \rangle \leq 6$$
证明思路：每个面至少由 3 条边围成，每条边最多被 2 个面共享，所以 $3f \leq 2m$。 代入欧拉公式 $f = 2 + m - n$ 得 $2m \geq 3(2+m-n) = 6 + 3m - 3n$， 整理出 $m \leq 3n - 6$。再用 $\langle k \rangle = 2m/n$ 即得 $\langle k \rangle \leq 6 - 12/n \leq 6$。

2.5 极大平面网络 (Maximal Planar)

极大平面网络：再加任何一条边都会变成非平面。 此时上述不等式取等号： $$m_{\max} = 3n - 6, \quad f_{\max} = 2n - 4, \quad f^*_{\max} = 2n - 5$$

例：$n=4$ → $m_{\max}=6$，$f_{\max}=4$（即四面体的展开图）。

3. 空间网络的度量指标

3.1 γ 指数（Gamma Index, Kansky 1963）

$$\gamma = \frac{m}{m_{\max}} = \frac{m}{3n - 6}$$ 边数与平面图最大可能边数之比，衡量平面网络的"边密度"。

3.2 α 指数（Alpha Index / Meshedness, Buhl 2006）

$$\alpha = \frac{f^*}{f^*_{\max}} = \frac{m - n + 1}{2n - 5}$$ 有界面数与最大可能有界面数之比。 $\alpha \in [0, 1]$：树时为 0，极大连接平面网时为 1。
γ 看的是"有多少边"，α 看的是"有多少环"。环越多，绕路选择越多，网络越密。

3.3 加权中心性

空间网络的边 $(i,j)$ 自带长度 $l_{ij}$。设 $L_{ij}$ 为按"总长度"算的最短路径长度。

加权 Closeness 中心性： $$c_i = \sum_j \frac{n}{L_{ij}}$$ 加权 Betweenness 中心性：用"最短长度路径"代替"最少跳数路径"重新计算。

3.4 绕行率指数 (Detour Index)

设 $L_{ij}$ = 沿网络的最短距离，$d_{ij}$ = 两点间的直线（欧氏）距离。

$$Q_{ij} = \frac{L_{ij}}{d_{ij}} \quad,\quad Q_i = \frac{1}{n-1}\sum_j Q_{ij} \quad,\quad Q = \frac{1}{n(n-1)}\sum_{i \neq j} Q_{ij}$$ $Q$ 衡量空间网络的效率：与"所有节点都用直线连接"的理想情况相比，绕了多少路。 $Q$ 越接近 1，越接近直连理想网。
$Q$ 是"沿网络的路径长度 / 直线距离"，比值 ≥ 1。 不要把分子分母弄反，也不要忘记 $d_{ij}$ 是欧氏直线距离而非另一条网络距离。

4. 几何网络模型 (Geometric Network Models)

这些模型的共同点：是否连接两个节点，由它们空间位置间的几何关系决定。

4.1 $k$-最近邻图 ($k$-NN)

每个节点连向距离它最近的 $k$ 个邻居（$k$ 固定）。

"我把 A 连到了我的最近邻 B" 不代表 "B 也只把 A 当成它的最近邻"——k-NN 图通常是有向或不对称的； 画无向图时一般约定"任一方向有就连"。

4.2 阈值图 / 圆盘图 (Disc / Threshold Graph)

两节点距离 < 一个固定阈值时相连。

关键点：这里的"距离"不必是地理距离，只要是合法度量即可。 课件举例：1851 / 1881 年英国与威尔士城市间，若火车通行时间 < 1 小时则连边。

4.3 Delaunay 三角剖分

连接三个节点 $p_1, p_2, p_3$ 形成三角形，当且仅当 过这三点的外接圆内部不含任何其他节点。

4.4 Gabriel 图 (Gabriel & Sokal, 1969)

连接两节点，当且仅当以它们连线为直径的圆内不含其他节点。

4.5 相对邻域图 (Relative Neighbourhood Graph, RNG)

连接两节点 $u, v$，当且仅当不存在第三点比 $u, v$ 二者距离都更近的节点。 （即两个分别以 $u$、$v$ 为圆心、$d(u,v)$ 为半径的圆的交集不含其他节点。）

4.6 最小生成树 (Minimum Spanning Tree, MST)

连接所有节点的、总边长最小的树。
MST 是成本最低的连通方案，但鲁棒性差： 因为是树，任意一个节点失效就会让网络分裂。

4.7 几何模型间的关系

RNG ⊆ GG ⊆ Delaunay：相对邻域图的边一定在 Gabriel 图中，Gabriel 图的边一定在 Delaunay 三角剖分中。
RNG 的"禁区"是两个大圆的交集——它比 Gabriel 图的小圆禁区更大。 "禁区越大 → 越难连边 → 边越少"。 所以 RNG 边数最少（最稀疏），Delaunay 边数最多（最稠密）。

5. 应用举例

5.1 地铁线路图 (Line Graph of Metro)

把每条线路当作一个节点，两条线路若共享站点则连边。 这样可直接读出"最多需要换乘几次"——即新网络中的直径（最大最短路径）。

5.2 街道方向性 (Street Orientation)

边除了"长度"外还有"方向、坡度"等属性。 Geoff Boeing 用 OSMnx 分析全球城市街道走向，画出"风玫瑰图"风格的方向分布。

6. 时间网络 (Temporal Networks)

时间网络：节点和边都是瞬时的，只在某些明确定义的时间段内存在。

别名：dynamic networks（动态网络）、time-varying（时变）、growing networks（生长网络，特指节点/边只增不减的情况）。

6.1 关键性质

  • 边出现的顺序和持续时长很重要（影响信息传播）
  • 可视作多层网络：选定时间步长 Δt，按时间切片成多层
  • 时间分辨率选择至关重要（太粗 → 丢信息；太细 → 噪音）

6.2 投影 (Projection)

投影网络：所有曾出现过的节点和边的并集——一张"静态总图"。
投影不包含全部信息！投影中存在的路径，在时间网络里不一定可行。

6.3 时间尊重路径 (Time-Respecting Path)

路径 $v_1 \to v_2 \to v_3$ 是"时间尊重"的，仅当 $v_2 \to v_3$ 这条边出现的时间不早于 $v_1 \to v_2$ 出现的时间。

像传"小道消息"：A 周一告诉 B，B 周三告诉 C —— 可行。 但如果 B 周一就告诉了 C，再 A 周三告诉 B，那 C 不可能从 A 那里听到周三的最新八卦。

6.4 可达性 (Reachability)

有向网络可达性：节点 $i$ 出发，通过有向路径能到达的所有节点集合。
时间可达性：通过时间尊重的有向路径能到达的所有节点集合。

6.5 课件中的八卦例子

A、B、C、D、E、F 一周内的相遇关系，由于具体时刻不明（A 与 C 周三相遇是早是晚不知道）， 出现了两种不同结局：

  • 场景 1（A 先于 D 见 C）：八卦逐步传遍全员
  • 场景 2（A 晚于 D 见 C）：E 和 F 周末都不知情

这是网络理论中"不确定性"的典型例子。改用更细的时间步长可以让模型更精确，但不能消除由数据本身缺失带来的不确定性。

第二部分 考点梳理

下表按"主题模块"组织所有考点，每条标注：重要程度（★★★ 高频 / ★★ 中等 / ★ 低频）和类型（记忆 / 理解 / 计算）。

模块 A：空间网络基础

A1. 空间网络的定义 ★★★ 高频
需记忆 需理解

定义：节点和边有空间位置 + 网络结构受空间影响或约束。连接两节点常有"距离相关的代价"。

关注的对象：节点位置、路径轨迹、节点间距离、边的长度。

易混淆：不是所有真实网络都该建模为空间网络。是否选空间模型，取决于研究问题是否真的关心距离（朋友关系网就是反例）。

模块 B：平面网络

B1. 平面网络的定义 ★★★ 高频
需记忆

定义：存在一种画法使所有边不相交的网络。

关键易错："can be drawn" —— 初始画法有交叉不代表不平面，只要能重画就是平面。

B2. Kuratowski 定理 ★★ 中等
需记忆 需理解

定理：网络非平面 ⟺ 包含 $K_5$ 或 $K_{3,3}$ 作为子网络。

常用判定结果：$K_5$（5 节点完全图）和 $K_{3,3}$（3+3 完全二部图）非平面，要记住。

B3. 欧拉公式 ★★★ 高频
需记忆 需计算

公式：$n - m + f = 2$（$f$ 包含外部面）；$n - m + f^* = 1$（$f^*$ 不含外部面）。

易错：$f$ 到底要不要加上外部那一个"无界面"是常考点。

证明要会复述：不断去掉环边到树，$N$ 不变；树时 $N=2$。

B4. 平面图平均度上界 ★★★ 高频
需记忆 需理解

结论：$\langle k \rangle \leq 6 - 12/n \leq 6$；以及 $m \leq 3n - 6$。

证明要点：每个面至少 3 边、每边至多 2 面 → $3f \leq 2m$；代入欧拉公式即得。

B5. 极大平面网络 ★★ 中等
需记忆 需计算

定义：再加任一条边都会变非平面。

关键公式（要会背）：$m_{\max}=3n-6$，$f_{\max}=2n-4$，$f^*_{\max}=2n-5$。

易错：这些上界只有极大平面图才取等号，一般平面图不满足等号。

模块 C：空间网络度量指标

C1. γ 指数（Gamma Index） ★★★ 高频
需记忆 需计算

公式：$\gamma = \dfrac{m}{3n-6}$

意义：平面网络的"边密度"。范围 $[0, 1]$。

来源：Kansky, 1963。

C2. α 指数（Alpha Index / Meshedness） ★★★ 高频
需记忆 需计算

公式：$\alpha = \dfrac{m-n+1}{2n-5}$

意义：有界面数密度（"环密度"）。树时 $\alpha = 0$，极大连接平面网时 $\alpha = 1$。

易混淆：γ 看边数比例；α 看环（有界面）比例。两者都衡量稠密程度但角度不同。

C3. 加权中心性 ★★ 中等
需理解 需计算

用总路径长度 $L_{ij}$（而不是"跳数"）作为路径成本，重新定义 closeness 与 betweenness。

加权 Closeness：$c_i = \sum_j n/L_{ij}$

C4. 绕行率（Detour Index） ★★★ 高频
需记忆 需计算

公式：$Q_{ij} = L_{ij}/d_{ij}$，$Q_i = \dfrac{1}{n-1}\sum_j Q_{ij}$， $Q = \dfrac{1}{n(n-1)}\sum_{i\neq j} Q_{ij}$

分子分母含义：分子 = 沿网络最短路径长度；分母 = 两点欧氏直线距离。

意义：衡量空间网络相对"全部直连理想网络"的效率。$Q \geq 1$，越接近 1 越高效。

易错：不要把分子分母弄反。

模块 D：几何网络模型

D1. $k$-最近邻图 ★★ 中等
需理解

每个节点连接其 $k$ 个最近邻居。关系不对称：A 把 B 当近邻，B 不一定把 A 当近邻。

D2. 阈值图 / 圆盘图 ★★ 中等
需理解

距离 < 阈值则连边。"距离"可以是任意合法度量（如旅行时间、相似度），不限于地理距离。

D3. Delaunay 三角剖分 ★★ 中等
需记忆 需理解

规则：三个节点形成三角形 ⟺ 过这三点的外接圆内部不含其他节点。

D4. Gabriel 图 ★★ 中等
需记忆

规则：两节点连边 ⟺ 以它们连线为直径的圆内不含其他节点。

D5. 相对邻域图 (RNG) ★★ 中等
需记忆

规则：两节点 $u,v$ 连边 ⟺ 不存在第三点同时比 $u,v$ 二者距离都近。

等价表述：以 $u,v$ 为圆心、$d(u,v)$ 为半径的两圆交集内无其他节点。

D6. 最小生成树 (MST) ★★ 中等
需理解

总边长最小的、连接所有节点的树。最经济但最不鲁棒（任一节点失效就分裂）。

D7. 几何模型间的包含关系 ★★★ 高频
需理解

关系：RNG ⊆ GG ⊆ Delaunay。

直观：RNG 的"禁区"是大圆交集（更大），所以连边条件更严，边更少。

模块 E：应用

E1. 地铁线路图（Line Graph of Metro） ★ 低频
需理解

每条线路当节点，共享站点的线路间连边。新网络的直径 = 最多换乘次数。

E2. 街道方向性 ★ 低频
需理解

空间网络的边除长度外，还有方向、坡度等属性可分析。

模块 F：时间网络

F1. 时间网络的定义 ★★★ 高频
需记忆

定义：节点和边只在某些明确定义的时间段中存在。

别名：动态网络、时变网络、生长网络（仅增不减）。

F2. 投影 (Projection) ★★★ 高频
需记忆 需理解

定义：包含所有曾出现的节点和边的静态网络。

关键限制：投影不能完全代表时间网络——投影中的路径不一定时间可行。

F3. 时间尊重路径 ★★★ 高频
需理解

定义：路径上相邻两条边的出现时间单调不减。

F4. 可达性 vs 时间可达性 ★★★ 高频
需理解

可达性：有向路径所能到的节点集。

时间可达性：仅通过时间尊重路径所能到的节点集。

关键点：边出现的顺序会改变可达节点集，进而影响信息传播。

F5. 不确定性 / 时间分辨率 ★★ 中等
需理解

当事件发生在同一时间步内、但顺序未知时，可达性会出现多种可能结果。 细化时间步可以提高精度，但不能消除原始数据缺失导致的不确定性。

1. 下列哪一项最准确地描述了空间网络？
  • A.所有节点都画在同一张地图上的网络
  • B.节点之间所有连接都必须用直线表示的网络
  • C.节点和边都有空间位置，且网络结构受空间影响或约束的网络
  • D.嵌入在二维平面中、所有边均不相交的网络
显示答案与解析 ▼
答案：C

解析：按课件定义，空间网络需满足两条：(1) 节点和边有空间位置；(2) 网络结构受空间影响或约束。

  • A 不准确：仅"画在地图上"不一定意味着结构受空间约束。
  • B 错误：边只是有"位置"和"长度"，不一定是直线（如城市道路可绕弯）。
  • D 描述的是平面网络（planar），是不同概念。

易错提醒："空间网络" ≠ "平面网络"。

  • C.$K_{3,3}$ 可以重新画成无交叉的形式，因此是平面网络
  • D.飞机航线网络通常不能近似为平面网络
显示答案与解析 ▼
答案：D

解析：

  • A 错：$K_5$ 是经典非平面图（Kuratowski 定理）。
  • B 错：平面性看"是否存在一种不相交画法"，初始画法有交叉不能下结论。
  • C 错：$K_{3,3}$ 也是经典非平面图。
  • D 正确：飞机航线显然有大量交叉，不能近似为平面图（不像道路网那样可以近似）。

易错提醒：$K_5$ 与 $K_{3,3}$ 是判定非平面的"特征子图"，要熟记。

[选择题] 考点 B3, B4：欧拉公式与度上界 [基础]
3. 欧拉公式 $n - m + f = 2$ 中的 $f$ 指：
  • A.网络中所有内部封闭区域的数量（不含外部面）
  • B.平面被边分割成的所有区域数（包括外部无界面）
  • C.所有三角形面的数量
  • D.所有可走的环路数量
显示答案与解析 ▼
答案：B

解析：$f$ 是平面被边分割出的所有面，包括那一片"包围在外面的"无界面。若不包括外部面，应使用 $f^* = f - 1$，对应公式 $n - m + f^* = 1$。

易错提醒：是否包括外部面是常考的"陷阱"——做题前先看清题目用的是 $f$ 还是 $f^*$。

[选择题] 考点 B5：极大平面网络 [中等]
4. 一个含 $n=8$ 个节点的极大平面网络，其边数 $m_{\max}$ 和有界面数 $f^*_{\max}$ 分别为：
  • A.$m_{\max}=15,\ f^*_{\max}=10$
  • B.$m_{\max}=20,\ f^*_{\max}=12$
  • C.$m_{\max}=18,\ f^*_{\max}=11$
  • D.$m_{\max}=14,\ f^*_{\max}=8$
显示答案与解析 ▼
答案：C

[选择题] 考点 C1, C2：γ 与 α 指数 [中等]
5. 关于 γ 指数和 α 指数，下列说法错误的是：
  • A.γ 指数衡量边数与最大可能边数之比
  • B.对一棵树，α 指数为 0
  • C.α 指数又称为 meshedness
  • D.γ 和 α 指数均可用于任意网络，无须假设网络是平面图
显示答案与解析 ▼
答案：D

解析：γ 和 α 指数的分母（$3n-6$、$2n-5$）来自平面图的极大边数 / 极大面数，这两个上界仅在平面图中成立。

因此严格地说，γ、α 指数是为平面网络（或可近似为平面的网络）设计的"密度指标"。对非平面网络（如完全图），公式仍能算，但含义会很奇怪（甚至会出现 $\gamma > 1$）。

  • A 正确：是 γ 的定义。
  • B 正确：树只有 $n-1$ 条边、无环，$f^* = 0$，故 $\alpha = 0$。
  • C 正确：α 又叫 meshedness。
[选择题] 考点 D7：几何模型包含关系 [中等]
6. 设 $E_\text{Del}$、$E_\text{GG}$、$E_\text{RNG}$ 分别是同一点集上的 Delaunay、Gabriel、相对邻域图的边集，则它们的包含关系为：
  • A.$E_\text{RNG} \subseteq E_\text{GG} \subseteq E_\text{Del}$
  • B.$E_\text{Del} \subseteq E_\text{GG} \subseteq E_\text{RNG}$
  • C.$E_\text{GG} \subseteq E_\text{RNG} \subseteq E_\text{Del}$
  • D.三者互不包含
显示答案与解析 ▼
答案：A

解析：RNG 的"禁区"（两大圆交集）比 GG 的"禁区"（小圆）更大，所以 RNG 中能保留的边更少。"禁区越大、边越少"，故 RNG ⊆ GG。同理 GG ⊆ Delaunay。

记忆口诀：RNG 最稀，Delaunay 最稠，Gabriel 居中。

[选择题] 考点 F2, F3：投影与时间尊重路径 [中等]
7. 关于时间网络（temporal network），下列说法正确的是：
  • A.投影网络包含了原始时间网络的全部信息
  • B.投影网络中存在的路径，未必是时间尊重路径
  • C.边出现的顺序不影响信息传播
  • D.选择越细的时间分辨率，结果就一定越确定
显示答案与解析 ▼
答案：B

解析：

  • A 错：投影只保留了"哪些边曾经出现"，丢失了时间顺序，信息有损。
  • B 正确：经典反例——投影里看似可行的 $v_1 \to v_3 \to v_4$，若 $v_3 \to v_4$ 出现得比 $v_1 \to v_3$ 早，就不可行。
  • C 错：边出现顺序极大地影响信息传播。
  • D 错：细化时间分辨率有助于减少混淆，但不能消除来自数据本身缺失的不确定性（如八卦案例的 Wed 1 / Wed 2 仍然不知道）。
[选择题] 考点 C4：绕行率 [中等]
8. 关于绕行率 $Q_{ij} = L_{ij}/d_{ij}$，下列说法错误的是：
  • A.$L_{ij}$ 是沿网络的最短路径长度
  • B.$d_{ij}$ 是两点间的欧氏直线距离
  • C.$Q_{ij}$ 可以小于 1，意味着走网络比走直线更快

其余选项均为正确表述。

[计算题] 考点 B3：欧拉公式 [基础]
20. 一个连通平面网络含 $n = 12$ 个节点、$m = 25$ 条边。 请分别计算其面数 $f$（含外部面）和有界面数 $f^*$。
显示答案与解析 ▼
解答：

由欧拉公式 $n - m + f = 2$： $$f = 2 - n + m = 2 - 12 + 25 = 15$$

有界面数：$f^* = f - 1 = 14$。

（也可直接用 $n - m + f^* = 1 \Rightarrow f^* = 1 - 12 + 25 = 14$。）

验证可行性：$m_{\max} = 3 \times 12 - 6 = 30 \geq 25$，所以这样的平面图是可以存在的。

[计算题] 考点 C1, C2 [中等]
21. 对上一题中的平面网络（$n = 12,\ m = 25$，假设连通），计算其 γ 指数和 α 指数。
显示答案与解析 ▼
解答：

$$\gamma = \frac{m}{3n-6} = \frac{25}{3 \times 12 - 6} = \frac{25}{30} = \frac{5}{6} \approx 0.833$$

$$\alpha = \frac{m-n+1}{2n-5} = \frac{25 - 12 + 1}{2 \times 12 - 5} = \frac{14}{19} \approx 0.737$$

解读：γ ≈ 0.83 说明边数已达"最大值"的 83%；α ≈ 0.74 说明有界面数已达"最大值"的 74%。两者均说明该网络较为稠密，介于树与极大平面图之间。

[计算题] 考点 B5 [基础]

[计算题] 考点 C4：绕行率 [中等]
23. 在某空间网络中，节点 $A$ 与 $B$ 的直线距离为 $d_{AB} = 5$ km， 但因为没有 $A$ 到 $B$ 的直接道路，沿网络最短路径长度为 $L_{AB} = 8$ km。 节点 $A$ 与 $C$ 的直线距离为 $d_{AC} = 10$ km， 沿网络最短路径长度为 $L_{AC} = 11$ km。计算 $Q_{AB}$、$Q_{AC}$ 与 $A$ 的绕行率 $Q_A$（假设网络只有 3 个节点）。
显示答案与解析 ▼
解答：

$$Q_{AB} = \frac{L_{AB}}{d_{AB}} = \frac{8}{5} = 1.6$$

$$Q_{AC} = \frac{L_{AC}}{d_{AC}} = \frac{11}{10} = 1.1$$

对节点 $A$：$Q_A = \dfrac{1}{n-1}\sum_{j \neq A} Q_{Aj} = \dfrac{1}{2}(Q_{AB} + Q_{AC}) = \dfrac{1.6 + 1.1}{2} = 1.35$

解读：从 $A$ 出发到其他节点，平均需要绕直线距离 35% 的路。 节点 $B$ 那个方向的网络效率较低（$Q=1.6$），节点 $C$ 方向较高效（$Q=1.1$）。

[计算题/作图] 考点 E1：地铁线路图 [中等]
24. 某地铁系统共 5 条线路 $L_1, L_2, L_3, L_4, S_1$，相互共享站点情况如下：
• $L_1$ 与 $L_2, L_3, L_4, S_1$ 均有共享站点（其中 $L_1$ 与 $L_4$ 有 2 个共享站点）
• $L_2$ 与 $L_3, L_4$ 也有共享站点
• $L_3$ 与 $L_4$ 有共享站点
• $S_1$ 只与 $L_1$ 共享站点
请构造其线路图（line graph），并回答：要从任意一条线路换乘到任意另一条线路，最多需要换乘几次？
显示答案与解析 ▼
解答：

邻接列表：

  • $L_1$: $L_2, L_3, L_4, L_4, S_1$（与 $L_4$ 有重边）
  • $L_2$: $L_1, L_3, L_4$
  • $L_3$: $L_1, L_2, L_4$
  • $L_4$: $L_1, L_1, L_2, L_3$
  • $S_1$: $L_1$

结构分析：$L_1, L_2, L_3, L_4$ 之间两两相连（构成 $K_4$）；$S_1$ 仅与 $L_1$ 相连，是"叶子"。

最远换乘：从 $S_1$ 到 $L_2$、$L_3$ 或 $L_4$，必须走 $S_1 \to L_1 \to$ 目标，需要换乘 2 次（"换乘次数 = 路径上的边数")。

易错提醒："换乘次数"对应线路图中的路径长度，不是站点数。线路图的直径就是最大换乘数。

[计算题] 考点 B3, C1 [综合]
25. 已知一个连通平面网络的 γ 指数为 0.6，节点数 $n = 20$。 （1）求边数 $m$；（2）求面数 $f$ 和有界面数 $f^*$；（3）若希望把它升级到 γ = 0.9，需要新增多少条边？（仍要求保持平面性）
显示答案与解析 ▼
解答：

(1) 求 $m$：$m_{\max} = 3n - 6 = 54$。由 $\gamma = m/m_{\max} = 0.6$： $$m = 0.6 \times 54 = 32.4 \to \text{取整 } m = 32 \text{（约 32 条）}$$

(2) 求面数：由 $f = 2 - n + m = 2 - 20 + 32 = 14$；$f^* = 13$。

(3) 新增边数：新的 $m' = 0.9 \times 54 = 48.6 \to 49$（取整）。需要新增 $49 - 32 = 17$ 条。 且 $49 \leq 54$，新增后仍满足平面图最大边数约束，所以原则上可行（具体能否还要看哪些位置能加边而不破坏平面性）。

易错提醒：γ 公式给出的 $m$ 通常不是整数，要按题意取整；说明工程实践中 γ 是一个连续度量，不要求对应整数边。

五、简答题（共 4 题）

[简答题] 考点 A1 [基础]
26. 简述"为什么不是所有真实网络都应该建模为空间网络"？请举一个反例并解释。
显示答案与解析 ▼
参考答案：

"空间网络"工具的核心价值在于处理空间约束。当节点之间的连接受到空间 / 距离的强制性约束时（如道路必须连接相邻地块），空间网络的指标（绕行率、γ/α、几何模型）才能给出有意义的结论。

若网络中节点的连接不受空间限制，强行使用空间网络模型反而会引入"不存在的约束"，分析结果不仅没有信息量，还可能误导。

反例：朋友关系网络。虽然朋友常常住得近（这是一个统计规律），但理论上人可以与全球任何地方的人成为朋友——网络结构没有"空间禁令"。如果研究的问题是"信息如何在朋友间传播"，使用普通的复杂网络指标（度分布、聚集系数等）就够了，引入"距离成本"反而是画蛇添足。 只有在研究问题本身关心距离（如"地理邻近性如何影响新朋友的产生概率"）时，空间网络才合适。

评分要点：(1) 指出"空间网络工具是为有空间约束的系统设计的"；(2) 给出合理反例；(3) 联系研究问题本身。

[简答题] 考点 C1, C2 [中等]
27. 比较 γ 指数和 α 指数：它们各自衡量什么？取值范围？分母为何不同？
显示答案与解析 ▼
参考答案：

γ 指数 $= m/(3n-6)$：衡量"边密度"——实际边数与平面图最大可能边数之比。 范围 $[0, 1]$，0 表示无边（孤立节点），1 表示极大平面（已不能加更多边）。

α 指数 $= (m-n+1)/(2n-5)$：又称 meshedness，衡量"环密度"——实际有界面数与平面图最大可能有界面数之比。 范围 $[0, 1]$，对树（无环）为 0；对极大连接平面网为 1。

分母不同的原因： γ 的"上界"是极大平面图的边数 $3n-6$； α 的"上界"是极大平面图的有界面数 $2n-5$。 这两个值都来自欧拉公式与"每面 ≥ 3 边"约束，但它们度量的对象不同（边 vs 面）。

对比要点：γ 看"有多少连接"；α 看"有多少冗余路径（环）"。 一个稀疏的网络可能 γ 很小但 α 也较小；一个稠密但接近树的"链状"网络 γ 会高但 α 仍低（环不多）。

[简答题] 考点 D3, D4, D5, D7 [中等]
28. 简述 Delaunay 三角剖分、Gabriel 图、相对邻域图（RNG）的连接规则，并解释它们之间的包含关系。
显示答案与解析 ▼
参考答案：

Delaunay 三角剖分：三点 $p_1, p_2, p_3$ 形成三角形（即两两连边） ⟺ 这三点的外接圆内部不含其他节点。

Gabriel 图：两节点 $u, v$ 连边 ⟺ 以 $\overline{uv}$ 为直径的圆内不含其他节点。

相对邻域图：$u, v$ 连边 ⟺ 不存在第三点同时比 $u, v$ 二者距离都近。 等价于：以 $u$、$v$ 为圆心、$d(u,v)$ 为半径的两圆交集（透镜形区域）不含其他节点。

包含关系：RNG ⊆ GG ⊆ Delaunay。 直观地，三种规则的"禁区"由小到大：Gabriel 是以连线为直径的小圆（最严的禁区中等）； RNG 是两个大圆交集（禁区最大、最难连边）； Delaunay 的约束最宽松。 所以 RNG 边数最少、Delaunay 边数最多，GG 居中。

[简答题] 考点 F3, F4 [中等]
29. 在时间网络中，为什么"投影"会丢失信息？请用一个例子说明"投影中的路径未必是时间尊重路径"。
显示答案与解析 ▼
参考答案：

投影丢失信息的原因：投影只保留"哪些边曾出现"，抹掉了时间戳。因此投影中相邻两条边的出现顺序信息丢失，无法判断真实网络中的传播是否可行。

例子（课件原例）：设有 4 个节点 $v_1, v_2, v_3, v_4$。时间序列： $t=0$ 时 $v_1 \to v_2$；$t=1$ 时 $v_3 \to v_4$；$t=2$ 时 $v_2 \to v_4$ 与 $v_1 \to v_3$ 都出现。

投影中可以看到从 $v_1$ 到 $v_4$ 有两条路径：经 $v_2$（即 $v_1 \to v_2 \to v_4$）和经 $v_3$（即 $v_1 \to v_3 \to v_4$）。

但时间网络中：

  • $v_1 \to v_2 \to v_4$：第一段在 $t=0$，第二段在 $t=2$，单调递增，时间尊重。
  • $v_1 \to v_3 \to v_4$：第一段（$v_1 \to v_3$）发生在 $t=2$，而第二段（$v_3 \to v_4$）发生在 $t=1$——第二段比第一段早！所以这条路径不时间尊重，信息无法这样传递。

结论：投影把"潜在可达性"与"实际可达性"混在一起，研究信息传播时必须用时间可达性而不是投影上的可达性。

[论述题] 考点 B3, B4 [综合]
30. 完整推导：连通平面图的平均度 $\langle k \rangle \leq 6$。请说清每一步的依据。
显示答案与解析 ▼
证明：

步骤 1：每个面至少由 3 条边围成。 因为面是闭合区域，至少需要一个由 3 条边构成的三角形（即使是平行边或自环，简单图中也满足这一约束）。 于是面被边围成的次数总和 $\geq 3f$。

步骤 2：每条边至多被 2 个面共享。 一条边在平面上把局部区域分成两侧，每侧最多对应一个面。所以面边对的总和 $\leq 2m$。

步骤 3：合并得 $3f \leq 2m$。 这是因为"面边对总数"既等于按面计的 $\geq 3f$，又等于按边计的 $\leq 2m$。

步骤 4：代入欧拉公式 $n - m + f = 2$，即 $f = 2 + m - n$。 $$3(2 + m - n) \leq 2m \Rightarrow 6 + 3m - 3n \leq 2m \Rightarrow m \leq 3n - 6$$

步骤 5：换算成平均度。由握手定理，$\sum_i k_i = 2m$，所以 $\langle k \rangle = 2m/n$。 $$\langle k \rangle = \frac{2m}{n} \leq \frac{2(3n-6)}{n} = 6 - \frac{12}{n} \leq 6$$

结论：连通平面图的平均度上界为 6，且随节点数增大而趋近 6。

易错提醒：这个证明默认"简单图"（无自环、无多重边）；自环和多重边会改变"每面 ≥ 3 边"的假设。

[综合题] 考点 F1, F3, F4, F5 [综合]
31. 一周内 4 个人 A、B、C、D 的相遇情况：A 周一见 B；B 周二见 C；C 周三见 D；A 周四见 D。
(1) 把这些相遇画成时间网络（节点 A、B、C、D，按周一到周四 4 个时间步）。
(2) 若 A 周一前知道一条秘密，并把秘密告诉每个他见到的人，秘密会传播到谁？
(3) 画出该网络的投影，并指出投影中是否存在"看起来通但实际不可行"的传播路径。
显示答案与解析 ▼
解答：

(1) 时间网络（按时间切片）：

  • $t=1$（周一）：边 $A$–$B$
  • $t=2$（周二）：边 $B$–$C$
  • $t=3$（周三）：边 $C$–$D$
  • $t=4$（周四）：边 $A$–$D$

(2) 秘密传播：

  • $t=1$：A 告诉 B → 知情者 = {A, B}
  • $t=2$：B 告诉 C → 知情者 = {A, B, C}
  • $t=3$：C 告诉 D → 知情者 = {A, B, C, D}
  • $t=4$：A 告诉 D（D 已知）。

所以所有 4 人都知道了秘密。这条链 $A \to B \to C \to D$ 时间严格递增，是时间尊重路径。

(3) 投影：4 条边：$A$–$B$、$B$–$C$、$C$–$D$、$A$–$D$。这是一个 4 节点的环（"四边形"）。

投影中存在但实际不可行的路径：例如 $D \to A \to B \to C$（即"信息从 D 反向传到 C"）。 投影上 $D$–$A$、$A$–$B$、$B$–$C$ 都存在，看似 D 可以把信息传给 C。但时间网络上：$D$ 通过 $A$–$D$ 才能影响 $A$，发生在周四（$t=4$）； 而 $A$–$B$ 在 $t=1$、$B$–$C$ 在 $t=2$，都早于 $t=4$。所以信息无法从 $D$ 在第 4 步后回传给 $C$（除非有未来的边）。

结论：投影的"可达性"高估了真正的时间可达性。

[综合题] 考点 D1–D7：几何模型综合 [综合]
32. 假设你在为某地设计应急通信基站。你已有 100 个候选基站的地理坐标，现在要在它们之间架设通信链路。 请讨论：你会优先考虑下列哪种几何模型来生成连接方案？为什么？至少分析 3 种模型的优缺点。
显示答案与解析 ▼
参考答案：

本题考察对几种几何模型优缺点的综合理解。"最佳"答案取决于权衡成本和鲁棒性，下面分析三种典型选择：

① 最小生成树（MST）：

  • 优点：总链路长度最小、施工与维护成本最低。
  • 缺点：不鲁棒。任意一个基站故障就会使一部分节点失去通信。 应急场景对鲁棒性要求很高，所以 MST 不适合作为主方案。

② $k$-最近邻图（如 $k=3$）：

  • 优点：每个节点都有多个连接，鲁棒性较好；实现简单。
  • 缺点：可能全局连通性差（有可能形成多个孤立簇）；且边数随 $k$ 线性增长，成本可观。

③ Gabriel 图：

  • 优点：连接规则有明确几何意义，得到的图是平面图且通常连通， 介于 RNG 和 Delaunay 之间，既不过于稀疏也不过于稠密；能保留近邻关系。
  • 缺点：实现稍复杂；某些区域链路仍可能过密。

推荐方案：实际工程中，通常以 Gabriel 图或 Delaunay 三角剖分作为基础结构，再叠加MST 保底，以兼顾鲁棒性和成本； 也可以在 Gabriel 图基础上加上几条"长距离捷径"链路，形成"小世界"结构以缩短整体通信延迟。

评分要点：(1) 至少给出 3 种模型；(2) 每种说明优缺点；(3) 联系应用情境（鲁棒性 / 成本 / 连通性）；(4) 有合理的权衡讨论。
