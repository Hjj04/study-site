PART 01

课程讲解

概览整体脉络

把"网络分析"看作不断变换视野的过程： 个体 → 邻域 → 全局。

  • L4：聚焦个体——用各种"中心性"（度、特征向量、closeness、betweenness）度量 一个节点有多重要。
  • L5（本章）：聚焦小群体——一个节点和它的邻居们组成的"圈子"有多紧密？ 用 cliques、k-cores、clustering coefficient 来刻画。

三个工具其实回答同一个问题，但角度不同：

工具 问的是什么 严格程度
Clique 这一群人是不是两两都认识？ 最严
$k$-core 这一群人里每个人是不是至少认识 $k$ 个本群成员？ 较松（clique 的推广）
Clustering coef. "朋友的朋友"也是朋友的比例有多高？ 统计量（一个数字）

模块 1Clique（团）

📘 定义
一个 clique（团）是网络中的一组节点，其中 任意两个节点之间都存在一条边。 含 $n$ 个节点的 clique 就是 $K_n$（完全图），共有 $\binom{n}{2}$ 条边。
一个 4-clique（$K_4$）
两个 3-clique，但没有 4-clique
（缺少 1-4 边）

例子：与二分图的关系

把二分图（如 "物品-小组" 的隶属关系）做 one-mode projection（单模投影），会自然产生一群 clique：

  • 投影到"物品"侧：每个小组里的所有物品两两连边 → 一个 clique；
  • 投影到"小组"侧：每个物品所在的所有小组两两连边 → 一个 clique。
🔑 关键洞察
"投影会自动制造 clique" 解释了为什么很多真实网络（共同作者网、共同演员网、共同购物网） 显得"非常紧密"——它们本质上是二分关系的投影。

模块 2$k$-core

📘 定义
$k$-core 是一个连通的节点子集，使得其中 每个节点至少与该子集中的 $k$ 个其他成员相连。

用大白话讲：k-core 比 clique 宽松——不要求两两都认识， 只要"每个人在群里都至少有 $k$ 个朋友"就行。

🔑 联系 clique
一个含有 $k+1$ 个节点的 $k$-core 就是一个 $(k+1)$-clique。
原因：$k+1$ 个节点里，每个节点都要连到剩下的 $k$ 个 → 两两相连 → clique。

检测算法：迭代剥皮

用一种"剥洋葱"的思路找 $k$-core：

  1. 删：删除所有度数 $< k$ 的节点（连同它们的边），得到子网络 $G'$。
  2. 再删：在 $G'$ 中，可能因为边的删除导致某些节点度数掉到 $k$ 以下——继续删。
  3. 重复，直到所有剩余节点度数都 $\geq k$。这些节点就构成了 $k$-core。
⚠ 常见错误
  • 只删一轮 ❌ 删边会导致连锁反应——必须迭代直到稳定。
  • $k$-core 的"度"是子图度 ✅ 是在剩下的子网络中的度， 不是原图的度。
  • $k$-core 不一定唯一连通分量 一个网络可以有几个互不连通的 $k$-core。
🔑 嵌套性质
$k$-core 总是 $(k-1)$-core 的子集。 所以高 $k$ 的 core 像一层层"洋葱中心"，依次嵌套。

为什么我们关心 $k$-core？

  • 识别影响力：高 $k$-core 的节点处于互相强化的密集连接中， 非常适合传播信息/疾病。
  • 层级可视化：高 $k$ 放中心，低 $k$ 放外围，得到"洋葱图"。
  • 过滤：扔掉低 $k$ 的"叶子节点"，剩下网络的骨架。
  • 韧性研究：去掉大量节点之后还连通的部分往往就是高 $k$-core。

$k$-core 与各种中心性的关系

每个节点都有一个 core number——它所属的最大 $k$-core 的 $k$ 值。

中心性与 core number 关系原因
Degree centrality 强相关 core number 为 $k$ 的节点度数至少为 $k$
Eigenvector centrality 常常强相关 都奖励"被连得好的邻居"
Closeness / Harmonic 关系弱 $k$-core 内部紧密 ≠ 距离全网都短
Betweenness 关系弱 桥接节点可能 core number 很低

课件用一个"两个 3-core 用一条链相连"的例子说明：链上的 $x$ 在 2-core， betweenness 高达 16；两端的 $y, z$ 在 3-core 里，但 betweenness 反而只有 15 和 0。 这说明 "高 $k$-core ≠ 高 betweenness"。

模块 3Clustering Coefficient（聚类系数）

基本概念：connected triple 与 triangle

📘 定义
  • Connected triple（连通三元组）：三个节点 $A, B, C$， 其中 $B$ 同时与 $A$ 和 $C$ 相连（$B$ 处于"中间"）。
  • Triangle（三角形）：三个节点两两相连。
一个 connected triple 是不是 triangle，取决于"两头"的 $A, C$ 是否也连着。

全局 clustering coefficient $C$

$$C = \frac{3 \times (\text{number of triangles})}{\text{number of connected triples}}$$

分子的 3 是因为一个 triangle 包含 3 个 connected triple （每个顶点都可以做"中间"）。所以 $C$ 也可理解为： "所有 connected triples 中，闭合成 triangle 的比例"。

例子：2 个三角形（123 与 234），8 个 connected triple
$C = \dfrac{3 \times 2}{8} = \dfrac{6}{8} = \dfrac{3}{4}$

Local clustering coefficient $C_i$

📘 定义
节点 $i$ 的 local clustering coefficient 是： "$i$ 的邻居两两之间，实际相连的比例"。 $$C_i = \frac{\text{$i$ 的邻居中相连的对数}}{\binom{d_i}{2}}$$ 特别地：当 $d_i = 1$ 时，规定 $C_i = 0$（只有一个邻居，无法形成对）。

Watts-Strogatz 聚类系数 $C_{WS}$

$$C_{WS} = \frac{1}{n}\sum_{i=1}^{n} C_i$$

即所有节点 local clustering 的平均值。

⚠ 易混淆：$C$ 与 $C_{WS}$ 不是同一个东西
  • $C$（全局）按 triangle 加权：高度数节点参与更多 triangle，影响更大；
  • $C_{WS}$（平均）按节点平均：每个节点权重相同，低度数节点也能"投票"。
它们的数值通常不相等。论文里要看清楚作者用的是哪个！

小结三大工具的取舍

工具本质用什么时候
Clique "严丝合缝"的小团体 找完全互联的核心圈子
$k$-core 层层嵌套的稳健内核 过滤+识别影响力+研究韧性
Clustering Coef. "三角闭合率"的统计量 量化整体 / 局部的"抱团程度"

考点梳理

按主题分类，标注重要程度： ★★★ 高频 ★★ 中等 ★ 低频。 标注"记忆"或"理解/计算"。

2.1 Cliques（团）

考点要点类型重要度
Clique 定义 一组节点，任意两个之间都有边。$n$ 节点的 clique 有 $\binom{n}{2}$ 条边。 记忆 ★★★
识别 clique 给定一个网络，判断/数出 clique 大小。 理解 ★★
二分图 one-mode projection 形成 clique 每个小组在 items 投影中形成 clique；每个 item 在 groups 投影中形成 clique。 理解 ★★
⚠ 易错点
  • "两个共享边的 3-clique"不是 4-clique（必须任意两节点相连）。
  • $K_n$ 的边数是 $\binom{n}{2} = \dfrac{n(n-1)}{2}$，不是 $n^2$。

2.2 $k$-cores

考点要点类型重要度
$k$-core 定义 连通节点子集，子集中每个节点度数 $\geq k$。 记忆 ★★★
检测算法 迭代删去度 $< k$ 的节点+边，直到稳定。 理解/计算 ★★★
嵌套性 $k$-core $\subseteq$ $(k-1)$-core。 记忆 ★★★
Clique 关系 $k+1$ 节点的 $k$-core $=$ $(k+1)$-clique。 理解 ★★
Core number 节点所属最大 $k$-core 的 $k$ 值。 记忆 ★★
$k_{\max}$ 网络中存在 $k$-core 的最大 $k$。 理解 ★★
应用 影响力识别、层级可视化、过滤、韧性。 记忆 ★★
与中心性关系 与 degree、eigenvector 强相关；与 closeness、betweenness 弱相关。 理解 ★★★
⚠ 易错点
  • "度"是子图度，不是原图度。剥层时每删一次都要更新。
  • $k$-core 不要求两两相连，与 clique 区分清楚。
  • 1-core 不等于"全网络"——只是没有孤立节点的部分。
  • 嵌套方向：$k$ 大 $\subseteq$ $k$ 小，不是反过来。

2.3 Clustering Coefficient

考点要点类型重要度
Connected triple 三节点 $A,B,C$，$B$ 与 $A$、$C$ 都相连。"中间"节点是 $B$。 记忆 ★★★
Triangle 三节点两两相连。 记忆 ★★★
全局 $C$ 公式 $C = \dfrac{3 \times \text{triangles}}{\text{connected triples}}$ 记忆/计算 ★★★
Local $C_i$ $C_i = \dfrac{\text{$i$ 邻居中相连对数}}{\binom{d_i}{2}}$；度为 1 时 $C_i = 0$。 记忆/计算 ★★★
$C_{WS}$（Watts-Strogatz） $C_{WS} = \dfrac{1}{n}\sum C_i$ 记忆/计算 ★★★
$C$ 与 $C_{WS}$ 区别 $C$ 按三角形加权，$C_{WS}$ 按节点平均；两者数值通常不等。 理解 ★★
⚠ 易错点
  • $C_i$ 的分母是 $\binom{d_i}{2}$，不是 $d_i$。
  • 计算 connected triple 时，每个 triangle 贡献 3 个 connected triple（每个顶点可以做中间）。所以公式分子要乘 3。
  • 度为 1 的节点 $C_i = 0$（约定），不是"未定义"。
  • 孤立节点（度为 0）：通常也设 $C_i = 0$；公式 $\binom{0}{2}=0$ 会让分母无意义。

3.1 选择题（点击选项作答）

Q1 选择 Clique 定义 基础
下列哪个说法正确描述了 clique？
  • A.所有节点度数都恰好为 $k$ 的连通子图
  • B.一组节点，其中任意两个节点之间都有边相连
  • C.至少包含 $k$ 条边的连通子图
  • D.直径不超过 $k$ 的连通子图
显示答案与解析 ▼
答案：B
解析
Clique 的定义就是"任意两节点之间都有边"（两两相连）。
A 描述的是 $k$-正则子图；C 关心边数总量但不要求两两相连；D 是"直径"概念，与 clique 无关。
易错提醒： $K_n$ 含 $n$ 个节点的 clique 中，每个节点度数为 $n-1$， 边数为 $\binom{n}{2}$——这是 clique 的"派生事实"，但不是定义本身。
Q2 选择 $k$-core 定义 基础
关于 $k$-core 的描述，正确的是：
  • A.$k$-core 中每个节点的度数恰好等于 $k$
  • B.$k$-core 中每个节点至少与子集中的 $k$ 个其他成员相连
  • C.$k$-core 是 $k$-clique 的别称
  • D.$k$-core 必须恰好包含 $k$ 个节点
显示答案与解析 ▼
答案：B
解析
$k$-core 要求度数 $\geq k$（至少），不是恰好等于 $k$，故 A 错。 $k$-core 比 clique 宽松——不要求两两相连，所以 C 错。 节点数没有约束（可以远多于 $k$），D 错。
易错提醒： "度数 $\geq k$" 中的"度数"是在子图中的度数，不是原网络中的度。
Q3 选择 $k$-core 嵌套性 进阶
关于 $k$-cores 的嵌套关系，下列说法正确的是：
  • A.$(k-1)$-core 是 $k$-core 的子集
  • B.$k$-core 是 $(k-1)$-core 的子集
  • C.$k$-core 与 $(k-1)$-core 没有包含关系
  • D.$k$-core 与 $(k+1)$-core 总是相等
显示答案与解析 ▼
答案：B
解析
$k$ 越大，要求越严，能"留下"的节点越少。 所以 $k$-core 一定是 $(k-1)$-core 的子集。 想象洋葱：高 $k$ 在中心，低 $k$ 包在外面层层套住。
易错提醒： 方向不要记反！记口诀："$k$ 大子集小"。
Q4 选择 Clique 与 $k$-core 进阶
一个恰好含有 $k+1$ 个节点的 $k$-core 等价于：
  • A.一个 $k$-clique
  • B.一个 $(k+1)$-clique
  • C.一棵树
  • D.一个完全二分图
显示答案与解析 ▼
答案：B
解析
有 $k+1$ 个节点，每个节点都要至少连到子集中的 $k$ 个。 但子集中"其它节点"恰好只有 $k$ 个！所以每个节点必须连到所有其他节点 → 两两相连 → 一个 $(k+1)$-clique。
易错提醒： 注意 clique 的"$k$"和 $k$-core 的"$k$"含义不同： clique 的 $k$ 是节点数；$k$-core 的 $k$ 是度数下限。 二者只在"节点数 $=$ 度数 $+ 1$"时统一。
Q5 选择 $k$-core 与中心性 进阶
在真实网络中，下列哪种中心性与 core number 通常表现出 较强相关性？
  • A.Betweenness centrality
  • B.Harmonic centrality
  • C.Eigenvector centrality
  • D.所有中心性都同样强相关
显示答案与解析 ▼
答案：C
解析
Eigenvector centrality 度量"连接到那些被连得好的节点的程度" ——这与 $k$-core "互相强化的密集连接"的思想吻合。 所以两者通常强相关。
Betweenness 在意"桥梁性"，与"内部密集"不直接相关； closeness/harmonic 关心距离，$k$-core 内部紧密不代表全网距离短。
易错提醒： "通常强相关"不等于"一定强相关"——病态情形（pathological cases）依然存在。 但 $k$-core 计算更直观、更易手算。
Q6 选择 二分图投影 基础
关于二分图的 one-mode projection，正确的描述是：
  • A.投影后必然形成一棵树
  • B.在 items 投影中，每个 group 对应的成员自然形成一个 clique
  • C.投影结果总是稀疏的
  • D.投影与原二分图结构无关
显示答案与解析 ▼
答案：B
解析
属于同一 group 的所有 item 在投影中两两相连——这正是 clique 的定义。 所以"二分图投影会自然产生 clique"。
A、C 都是错误一般化——投影常常很密，因为大 group 会创造大 clique。
易错提醒： 这个性质提醒我们：在合作者网、共同观影网这类网络中观察到的"高聚类系数" 并不一定意味着"真实的强关系"，可能只是投影制造出来的。
Q7 选择 Clustering coefficient 公式 基础
全局 clustering coefficient $C$ 的正确公式是：
  • A.$C = \dfrac{\text{triangles}}{\text{node count}}$
  • B.$C = \dfrac{3 \times \text{triangles}}{\text{connected triples}}$
  • C.$C = \dfrac{\text{connected triples}}{3 \times \text{triangles}}$
  • D.$C = \dfrac{\text{triangles}}{\text{edge count}}$
显示答案与解析 ▼
答案：B
解析
$C$ 衡量的是"connected triples 中闭合成 triangle 的比例"。 每个 triangle 包含 3 个 connected triple（每个顶点都能做中间）， 所以分子要乘 3。
C 是公式 B 的倒数；A、D 完全无对应概念。
易错提醒： 公式中的 "3" 不能省略。如果省略，$C$ 的最大值就不是 1， 而是 $1/3$，不符合"比例"语义。
Q8 选择 Local clustering coefficient 进阶
设节点 $i$ 的度为 $d_i$。其 local clustering coefficient $C_i$ 的分母应为：
  • A.$d_i$
  • B.$2 d_i$
  • C.$\binom{d_i}{2} = \dfrac{d_i(d_i-1)}{2}$
  • D.$d_i^2$
显示答案与解析 ▼
答案：C
解析
$C_i$ 是 "$i$ 的邻居中实际相连的对数 / 可能存在的邻居对总数"。 $d_i$ 个邻居能形成 $\binom{d_i}{2}$ 个不同的对， 这就是分母。
易错提醒： 当 $d_i = 1$，$\binom{1}{2} = 0$（分母为零）。 约定 $C_i = 0$（"形不成对"）。

3.2 填空题

F1 填空 $k$-core 嵌套 基础
一个 4-core 同时也是 ____-core、____-core 和 ____-core。 （按从大到小填）
显示答案与解析 ▼
答案：3、2、1
解析
由嵌套性 $k\text{-core} \subseteq (k-1)\text{-core}$： 4-core 中的节点度数 $\geq 4 \geq 3 \geq 2 \geq 1$， 自动满足所有更小 $k$ 的条件。
F2 填空 Core number 基础
节点 $i$ 所属的最大 $k$-core 中的 $k$ 值，叫做节点 $i$ 的 ____________。
显示答案与解析 ▼
答案：core number（核数）
解析
这是 $k$-core 之上定义的节点级别指标，把"节点处于多深的洋葱中心"量化为一个数。 高 core number 节点往往同时具备高 degree centrality 和高 eigenvector centrality。
F3 填空 公式默写 进阶
Watts-Strogatz 聚类系数的公式为：$C_{WS}$ $=$ ____________。
显示答案与解析 ▼
答案： $C_{WS} = \dfrac{1}{n}\sum_{i=1}^{n} C_i$
解析
就是 local clustering coefficient 的算术平均。 它与全局 $C$ 不同：$C_{WS}$ 把每个节点同等对待， $C$ 实际上以"参与的 triple 数"为权重，更重视高度数节点。

3.3 判断题

T1 判断 Clique vs $k$-core 基础
$k$-core 中的所有节点都两两相连。（ 对 / 错 ）
显示答案与解析 ▼
答案：错（False）
解析
$k$-core 只要求每个节点至少与子集中的 $k$ 个其他成员相连， 并不要求两两相连。"两两相连"是 clique 的属性。 只有特殊情形（节点数 $= k+1$）下 $k$-core 才退化为 clique。
易错提醒： 这是 clique 和 $k$-core 最常考的区分点，必须分清。
T2 判断 度与 core number 进阶
一个节点度数很高，它的 core number 也一定很高。（ 对 / 错 ）
显示答案与解析 ▼
答案：错（False）
解析
一个节点度数高，只说明邻居多。但如果这些邻居之间彼此连接稀疏， 那么剥层算法很快就会把它们删掉，节点也会被"连坐"删除。
反过来才对：core number 为 $k$ 的节点，度数 $\geq k$（必要条件）。
易错提醒： 典型反例：一个"星形结构"的中心节点度数极高，但 core number 只有 1 （它的叶子节点之间没有连接，剥一次就只剩它孤零零的）。
T3 判断 $K_n$ 的 $C_i$ 基础
在完全图 $K_n$（$n \geq 2$）中，每个节点的 local clustering coefficient 都是 1。 （ 对 / 错 ）
显示答案与解析 ▼
答案：对于 $n \geq 3$ 时正确； $n = 2$ 时 $C_i = 0$（约定，因度数为 1）。
解析
$K_n$ 中节点 $i$ 的 $d_i = n-1$ 个邻居两两都相连， 所以邻居对中相连的占比 $= \dfrac{\binom{n-1}{2}}{\binom{n-1}{2}} = 1$。 只有 $n = 2$（即一条边）时 $d_i = 1$，按约定 $C_i = 0$。
T4 判断 $C$ 与 $C_{WS}$ 进阶
对任意网络，全局 $C$ 与 Watts-Strogatz $C_{WS}$ 数值相等。（ 对 / 错 ）
显示答案与解析 ▼
答案：错（False）
解析
两者定义不同：
• $C$ 是"全网 triangle 数量 / 全网 connected triples 数量"， 隐含按 triple 加权 → 偏向高度数节点。
• $C_{WS}$ 是"每个节点 $C_i$ 的平均"，每个节点权重相同 → 受低度数节点影响也大。
只有当所有 $C_i$ 完全相等（极特殊情形）时它们才数值相等。

3.4 简答题

S1 简答 Clique vs $k$-core 进阶
解释 clique 与 $k$-core 的区别，并说明二者之间的联系。
显示答案与解析 ▼
参考答案（建议结构）
区别（严格程度）：
  • Clique：要求子集中任意两节点之间都有边——最严的"两两相连"。
  • $k$-core：每个节点至少与子集中的 $k$ 个成员相连，不必两两相连——更宽松。
联系：$k$-core 是 clique 的推广。 特殊地，一个含有 $k+1$ 个节点的 $k$-core 就是 $(k+1)$-clique （因为 $k+1$ 个节点中要连到剩余 $k$ 个 = 两两相连）。
易错提醒： 回答时一定要说"宽松/严格"这层关系，并用 $k+1$ 节点的例子说明它们何时统一。
S2 简答 $k$-core 检测算法 进阶
描述 $k$-core 检测算法的步骤，并说明为什么需要"迭代"。
显示答案与解析 ▼
参考答案
算法步骤：
  1. 在原网络 $G$ 中删除所有度数 $< k$ 的节点（连同它们的边），得到 $G'$。
  2. 在 $G'$ 中继续删除度数 $< k$ 的节点和边，得到 $G''$。
  3. 重复此过程，直到剩余节点的度数都 $\geq k$。最终剩下的节点集合就是 $k$-core。
为什么要迭代：删除一个节点会同时删除它的邻边， 这可能使原本度数 $\geq k$ 的节点度数降至 $k$ 以下，触发"连锁删除"。 只有不断重复删除，才能保证最后剩下的每个节点在剩余子图中度数都 $\geq k$。
S3 简答 $k$-core 应用 基础
请列举 $k$-core 的至少三种实际应用场景，并简要说明原因。
显示答案与解析 ▼
参考答案（任选三项即可）
  • 识别信息/疾病传播的关键节点——高 $k$ 节点的邻居互相强化连接，传播路径多。
  • 层级可视化——把高 $k$ 放中心、低 $k$ 放外围，形成"洋葱图"。
  • 网络过滤——剥掉低 $k$ 的"叶子"，留下结构骨架，便于分析。
  • 韧性研究——随机删节点后还连通的部分往往就是高 $k$-core。
S4 简答 $C$ 与 $C_{WS}$ 进阶
解释全局 clustering coefficient $C$ 与 Watts-Strogatz 系数 $C_{WS}$ 的差异，并指出在哪种情况下高度数节点会让两者明显不同。
显示答案与解析 ▼
参考答案
  • $C$（全局） $= \dfrac{3 \times \text{triangles}}{\text{connected triples}}$： 直接对 triangle 计数，本质上按 triple 加权。 高度数节点参与的 triple 多，对 $C$ 的影响远大于低度数节点。
  • $C_{WS}$（平均） $= \dfrac{1}{n}\sum C_i$： 对每个节点的 $C_i$ 简单平均，所有节点权重相同。
差异显著的情形：当网络中存在"低度数但 $C_i = 1$"的节点 （例如"叶子三角形"），它们会拉高 $C_{WS}$； 而少数高度数中心节点若 $C_i$ 低（连接四散），会拉低 $C$。 于是 $C_{WS}$ 高、$C$ 低，差距明显。

3.5 计算题

C1 计算 全局 $C$ 进阶
对下面 4 个节点、5 条边的网络（节点 1,2,3,4；边：1-2, 1-3, 2-3, 2-4, 3-4）， 计算其全局 clustering coefficient $C$。
显示答案与解析 ▼
答案：$C = \dfrac{3}{4}$（即 $6/8$）
完整步骤
第 1 步：找 triangle。
节点 1,2,3：1-2, 1-3, 2-3 三边全在 → ✓ triangle (1,2,3)
节点 2,3,4：2-3, 2-4, 3-4 三边全在 → ✓ triangle (2,3,4)
节点 1,2,4：1-4 不存在 → ✗
节点 1,3,4：1-4 不存在 → ✗
共 2 个 triangle。

第 2 步：数 connected triples（按中间节点）。
  • 中间是 1，邻居 $\{2,3\}$：1 个 triple (2-1-3)
  • 中间是 2，邻居 $\{1,3,4\}$：$\binom{3}{2}=3$ 个 triples (1-2-3, 1-2-4, 3-2-4)
  • 中间是 3，邻居 $\{1,2,4\}$：3 个 triples (1-3-2, 1-3-4, 2-3-4)
  • 中间是 4，邻居 $\{2,3\}$：1 个 triple (2-4-3)
共 $1+3+3+1 = 8$ 个 connected triple。

第 3 步：套公式。 $$C = \dfrac{3 \times 2}{8} = \dfrac{6}{8} = \dfrac{3}{4}$$
易错提醒： 数 connected triple 的标准方法是"按中间节点"：对每个节点 $i$， 其邻居中能形成的 triple 数为 $\binom{d_i}{2}$。本题中 $\binom{2}{2} + \binom{3}{2} + \binom{3}{2} + \binom{2}{2} = 1+3+3+1 = 8$。
C2 计算 Local $C_i$ 与 $C_{WS}$ 进阶
在 C1 的同一网络（4 节点 5 边）中：
(a) 计算每个节点的 local clustering coefficient $C_i$；
(b) 计算 Watts-Strogatz 聚类系数 $C_{WS}$。
显示答案与解析 ▼
答案： $C_1 = 1$, $C_2 = \tfrac{2}{3}$, $C_3 = \tfrac{2}{3}$, $C_4 = 1$； $C_{WS} = \dfrac{5}{6}$
完整步骤
节点 1：邻居 $\{2,3\}$，$d_1 = 2$， 可能对数 $\binom{2}{2}=1$；实际相连对：$(2,3)$ ✓。 $$C_1 = \dfrac{1}{1} = 1.$$
节点 2：邻居 $\{1,3,4\}$，$d_2 = 3$， 可能对数 $\binom{3}{2}=3$；实际相连对：$(1,3)$ ✓, $(1,4)$ ✗, $(3,4)$ ✓ → 2 对。 $$C_2 = \dfrac{2}{3}.$$
节点 3：邻居 $\{1,2,4\}$，$d_3 = 3$。 实际相连对：$(1,2)$ ✓, $(1,4)$ ✗, $(2,4)$ ✓ → 2 对。 $$C_3 = \dfrac{2}{3}.$$
节点 4：邻居 $\{2,3\}$，$d_4 = 2$；$(2,3)$ ✓。 $$C_4 = 1.$$
$C_{WS}$： $$C_{WS} = \dfrac{1}{4}\left(1 + \dfrac{2}{3} + \dfrac{2}{3} + 1\right) = \dfrac{1}{4} \cdot \dfrac{10}{3} = \dfrac{10}{12} = \dfrac{5}{6}.$$
易错提醒： 注意 $C_{WS} = \tfrac{5}{6} \neq C = \tfrac{3}{4}$ —— 这就是教材说的"$C_{WS}$ 与全局 $C$ 是不同的概念"的具体例子。
C3 计算 $k$-core 检测 进阶
考虑一个 5 节点网络 $V = \{a,b,c,d,e\}$， 边集：$\{a$-$b, a$-$c, a$-$d, b$-$c, b$-$d, c$-$d, d$-$e\}$。
请分别求出 1-core、2-core、3-core，并指出最大 $k_{\max}$。
$\{a,b,c,d\}$ 形成 $K_4$（四面体），节点 $e$ 通过 $d$-$e$ 边接在外面。
显示答案与解析 ▼
答案： 1-core $= \{a,b,c,d,e\}$（全图）； 2-core $= \{a,b,c,d\}$； 3-core $= \{a,b,c,d\}$； 没有 4-core，故 $k_{\max} = 3$。
完整步骤
各节点原始度数：$d_a=3, d_b=3, d_c=3, d_d=4, d_e=1$。

1-core：删去度 $< 1$ 的节点——没有，所以 1-core 就是全图 $\{a,b,c,d,e\}$。

2-core：
  • $e$ 的度 $= 1 < 2$ → 删 $e$ 及边 $d$-$e$。
  • 剩余子图 $\{a,b,c,d\}$ 中：$d_a=3, d_b=3, d_c=3, d_d=3$，全部 $\geq 2$。停止。
所以 2-core $= \{a,b,c,d\}$。

3-core：再剥一层
  • 当前子图中各节点度均为 3 ≥ 3，无人被删。
所以 3-core $= \{a,b,c,d\}$（即 $K_4$ 本身——这也印证了"$k+1$ 节点的 $k$-core = $(k+1)$-clique"）。

4-core：要求度 $\geq 4$。$K_4$ 内每个节点度数 $= 3 < 4$，全部要删——没有 4-core。

因此 $k_{\max} = 3$。
易错提醒： 注意"度"始终是在当前子图中算的。例如删了 $e$ 之后， $d_d$ 从 4 降到 3，但仍 $\geq 3$，所以不会进一步触发删除。
C4 计算 综合：core + $C_i$ 综合
仍以 C3 的网络（$K_4$ + 尾节点 $e$）为例：
(a) 写出每个节点的 core number；
(b) 计算每个节点的 local clustering coefficient $C_i$；
(c) 计算 $C_{WS}$。
显示答案与解析 ▼
答案： (a) $a, b, c, d$ 的 core number $= 3$，$e$ 的 $= 1$； (b) $C_a = C_b = C_c = 1$, $C_d = \tfrac{1}{2}$, $C_e = 0$； (c) $C_{WS} = \dfrac{7}{10}$。
完整步骤
(a) Core numbers：
由 C3 结论，$a,b,c,d$ 在 3-core 中（最大可达 $k=3$）； $e$ 只在 1-core 中。所以 $\text{cn}(a)=\text{cn}(b)=\text{cn}(c)=\text{cn}(d)=3$， $\text{cn}(e)=1$。

(b) Local clustering：
节点 $a$：邻居 $\{b,c,d\}$，$d_a=3$，对数 $\binom{3}{2}=3$； 相连对 $(b,c),(b,d),(c,d)$ 全部存在（$K_4$ 内）→ 3 对。 $$C_a = 3/3 = 1.$$ 同理 $C_b = C_c = 1$（对称）。

节点 $d$：邻居 $\{a,b,c,e\}$，$d_d=4$，对数 $\binom{4}{2}=6$； 相连对 $(a,b),(a,c),(b,c)$ 存在（$K_4$ 内）→ 3 对； 其余 $(a,e),(b,e),(c,e)$ 均不存在。 $$C_d = 3/6 = 1/2.$$
节点 $e$：$d_e=1$ → 按约定 $C_e = 0$。

(c) $C_{WS}$： $$C_{WS} = \dfrac{1}{5}\left(1+1+1+\dfrac{1}{2}+0\right) = \dfrac{1}{5} \cdot \dfrac{7}{2} = \dfrac{7}{10}.$$
易错提醒： 节点 $d$ 容易算错——它有 4 个邻居（包括 $e$），所以分母是 $\binom{4}{2}=6$， 而不是"算到 $K_4$ 内部"的 3。$e$ 虽然只孤零零地挂在外面，但作为 $d$ 的邻居， 它会拉低 $d$ 的 $C_d$。

3.6 综合论述题

D1 论述 综合分析 综合
在 2014 年航班网络的研究中，研究者发现 93 个机场构成了 31-core。 请结合本章内容，论述：
(1) 这 93 个机场具有什么样的拓扑特征？
(2) 为何 core number 与 degree、eigenvector centrality 相关性强，与 harmonic centrality 几乎不相关？
(3) 你能否仅凭高 core number 就断定一个机场具有高 betweenness centrality？为什么？
显示答案与解析 ▼
参考答案要点
(1) 拓扑特征：93 个机场构成 31-core 意味着在这个 93 节点的子图中， 每个节点都至少与其他 31 个机场有直飞航线相连。 这表明这是一个极度密集互联的"枢纽圈"： 全是大型国际航空枢纽，互相之间几乎都有直飞，可形成大量冗余路径与"互相强化"的连接。

(2) 关系差异：
• 与 degree：core number 为 31 的节点度数必然 $\geq 31$ → 必然属于"超高度数集群"；
• 与 eigenvector：eigenvector 测量"连接到那些被连得好的节点的程度"—— 高 $k$-core 的节点正是邻居也都被连得好，互相强化提升 eigenvector 值；
• 与 harmonic/closeness：core 强调"内部紧密"， 不等于"到全网平均距离短"。许多大枢纽地理上集中（如欧美）， 到其他大陆小机场的距离仍可能较长 → 相关性弱甚至几乎为零。

(3) 高 core ≠ 高 betweenness：
不能仅凭 core number 推断 betweenness。 一个 core 内部节点彼此有多条冗余最短路径， 它们之间的最短路径不必经过任何特定节点 → 反而稀释了 betweenness。 课件中"两个 3-core 用一条链相连"的例子（$x$ 在链中间为 2-core，betweenness 最高 16； 两端 3-core 中的 $y, z$ betweenness 反而是 15 和 0）正说明这一点： 桥梁性由网络的"瓶颈位置"决定，而非"内部抱团程度"。
答题建议： 论述题要分层次：先准确翻译概念（"31-core 意味着什么"）， 再解释机制（为什么相关 / 不相关），最后用反例支撑结论。
