L6 Communities 期末复习梳理

基于 Matteo Mazzamurro 的 L6_Communities 课件 + L6_Communities_in_the_line_graph 习题

第一部分 · 课程内容讲解

📍 整体知识脉络

这节课在解决一个问题：给定一张网络（节点 + 边），如何把它划分成几个"团伙"（社团）？

课程的逻辑链条是这样的：

  1. 提出问题：之前学过中心性（关注单点）、聚类系数（关注邻居）、k-core（嵌套结构），但都没有回答"网络由几个紧密小团体组成"。于是引入 社团（Community） 的概念。
  2. 定义"好坏"：怎么判断一个分组方案好不好？答：与"随机连接"的版本对比，看组内边是不是显著更多。把这个对比量化，就是 模块度函数 Q（Modularity）。
  3. 找最优分组：理论上枚举所有分组方案，挑 Q 最大的。但是 n 个节点有 $2^n$ 种二分方式，太多了。于是引入 启发式算法（Node-moving / Girvan-Newman / Greedy / Louvain）来近似求解。

一句话：社团 → 用 Q 打分 → 用算法找最大 Q。

🔹 模块 1：什么是社团（Community）？

定义 社团是网络中的一组节点，它们之间内部连接密集，但与网络其他部分连接稀疏。
🌰 通俗类比 想象一个学校的人际关系网：高一(1)班的同学之间几乎都互相认识（内部密集），但他们和高三(5)班的同学几乎不认识（外部稀疏）。每个班级就是一个"社团"。又比如经典的 Zachary 空手道俱乐部：因为教练和管理员意见不合，俱乐部最终分裂成两派，每派内部联系紧密——这就是网络科学最有名的社团检测案例。

社团检测的目标

把网络划分为若干节点集合（社团），使得：

  • 社团内（within）：节点之间连接密集（densely connected）
  • 社团间（between）：节点之间连接稀疏（sparsely connected）

🔹 模块 2：模块度函数 Q —— 给分组方案打分

核心思路：和"随机网络"比一比

怎么知道一个分组方案是"真的好"，还是"恰巧组内边多"？办法是：把原网络的边"打散"，保留每个节点的度不变，然后随机重连。再问：

💡 核心问题 原网络中同组的边数，是否比随机网络中同组的边数明显更多？多得越多，分组越好。

逐项拆解模块度公式

① 实际同组的边数（$Q_1$）：

$$Q_1 = \sum_{\text{edge}(i,j)} \delta_{g_ig_j} = \frac{1}{2}\sum_{i,j} A_{ij}\,\delta_{g_ig_j}$$

其中：

  • $g_i$：节点 $i$ 所属的组
  • $\delta_{g_ig_j} = 1$ 当 $g_i = g_j$（同组），否则为 0 —— 这叫 Kronecker delta，可以理解成"同组开关"。
  • $A_{ij}$ 是邻接矩阵元素，相邻为 1，否则为 0
  • $\frac{1}{2}$ 是因为 $\sum_{i,j}$ 会把每条边数两次

② 随机网络中同组的期望边数（$Q_2$）：

$$Q_2 = \frac{1}{2}\sum_{i,j} \frac{k_ik_j}{2m}\,\delta_{g_ig_j}$$

关键是理解 $\frac{k_ik_j}{2m}$：在保度数随机重连的模型里，节点 $i$ 和 $j$ 之间的期望连边数恰好是 $\frac{k_ik_j}{2m}$。

🌰 直觉解释 $\frac{k_ik_j}{2m}$ 把每条边想成两根"半边"。所有半边总数是 $2m$。节点 $i$ 有 $k_i$ 根半边，节点 $j$ 有 $k_j$ 根半边。$i$ 的某根半边随机连到 $j$ 的某根半边的概率是 $\frac{k_j}{2m-1} \approx \frac{k_j}{2m}$。$i$ 有 $k_i$ 根半边都可以尝试，所以期望连边数 $\approx \frac{k_ik_j}{2m}$。

③ 模块度 Q 的最终定义：

$$Q = \frac{1}{2m}(Q_1 - Q_2) = \frac{1}{2m}\sum_{i,j}\left(A_{ij} - \frac{k_ik_j}{2m}\right)\delta_{g_ig_j}$$

除以 $\frac{1}{2m}$ 是把它标准化到 $[-\frac{1}{2}, 1)$ 区间，方便不同规模的网络互相比较。

简洁记号

令 $B_{ij} = A_{ij} - \frac{k_ik_j}{2m}$，称为 模块度矩阵。则：

$$Q = \frac{1}{2m}\sum_{i,j} B_{ij}\,\delta_{g_ig_j}$$

性质：$\sum_j B_{ij} = 0 = \sum_i B_{ij}$（B 矩阵的每行/每列和都为 0）。

🔹 模块 3：经典例子——线图（Line Graph）

把 $n$ 个节点排成一条线，相邻相连。如果在任意一条边上一刀切开，左边 $r$ 个、右边 $n-r$ 个节点，会发生什么？

关键事实：

  • 边数 $m = n-1$
  • 两端节点度为 1：$k_1 = k_n = 1$
  • 中间节点度为 2：$k_i = 2$（$2 \le i \le n-1$）

推导结果：

$$Q = \frac{3 - 4n + 4nr - 4r^2}{2(n-1)^2}$$

求最优 $r$： 对 $r$ 求导令其为 0：

$$\frac{dQ}{dr} = \frac{4n - 8r}{2(n-1)^2} = 0 \Rightarrow r = \frac{n}{2}$$

二阶导 $-8 < 0$，确认是极大值。

📌 结论
  • $n$ 为偶数：最佳切法是从正中间切，即 $r = n/2$。
  • $n$ 为奇数：$r$ 必须为整数，所以取 $r = \frac{n-1}{2}$ 或 $r = \frac{n+1}{2}$（两个对称解，Q 值相同）。

🔹 模块 4：从枚举到启发式——为什么需要算法

把 $n$ 个节点分成 2 个社团，有多少种方式？$2^n$ 种。对 $n=100$ 已经是天文数字，根本不可能穷举。所以必须用启发式算法找近似解。

算法 ①：Node-moving（节点移动）算法

  1. 把节点随机平分为两组。
  2. 开始一轮：每轮中，对每个节点，计算它"换边站队"会带来的 $\Delta Q$。挑 $\Delta Q$ 最大的那个节点移动。
  3. 已经移动过的节点本轮不能再移动。所有节点都移动一次后，本轮结束。
  4. 在本轮所有中间状态里，挑 Q 最大的那个分组作为本轮结果。
  5. 以本轮结果为新起点，重复上述步骤，直到 Q 不再提升。
🌰 类比 像两队拔河，但每个人只许换一次队。每轮看谁"换边能让组合最舒服"，让他换；然后下一个；直到所有人都被"试过一次"，记下其中最好的中间状态。

算法 ②：Girvan-Newman（基于边介数）算法

边介数定义 $$x_e = \sum_{\substack{j,k \\ j \ne k}} \frac{\sigma_{jk}(e)}{\sigma_{jk}}$$ 其中 $\sigma_{jk}$ 是 $j \to k$ 的最短路径数，$\sigma_{jk}(e)$ 是其中经过边 $e$ 的最短路径数。

算法步骤：反复执行——计算所有边的介数 → 删除介数最高的边 → 重新计算介数 → 继续删 → 直到网络分裂成若干连通分量。

🌰 直觉 社团之间通常只靠少数"桥梁边"相连。桥梁边承载了大量跨社团最短路径，所以介数最高。砍断桥梁，社团就显形了。
⚠️ 易错 每删一条边后，必须重新计算介数，不能用之前的旧值。

算法 ③：Greedy Modularity（贪婪模块度）算法

  1. 初始：每个节点单独成一个社团（$n$ 个节点 → $n$ 个社团）。
  2. 对每一对社团，计算"合并它们"会带来的 $\Delta Q$。
  3. 合并 $\Delta Q$ 最大的那一对。
  4. 重复直到不能再增加 Q。

这是 自底向上的凝聚，与 Girvan-Newman 自顶向下分裂相反。

算法 ④：Louvain 算法 ⭐

以发明者所在的比利时鲁汶大学命名。非常快，时间复杂度 $O((m+n)\log n)$。

核心思想：自底向上、多层级聚合

  1. 初始：每个节点单独一组。
  2. 对每个节点，尝试把它加入某个邻居所在的组——只要能提升 Q，就移过去；否则留在原地。
  3. 所有节点都考虑过后，重复第 2 步，直到 Q 不再提升。
  4. 把当前每个组"凝聚"成一个超级节点，得到一个新网络。
  5. 在新网络上重复 2–3 步。
  6. 直到无法再提升 Q，输出结果。
🌰 类比 就像家族聚会：第一轮是"几个个人组小家庭"（小社团形成），第二轮是"几个小家庭组成家族"（小社团聚成大社团），层层套娃。

🔹 模块 5：习题——环图（2-regular ring lattice）

n 个节点首尾相接成环，编号 1 到 n。把它分成 $\{1, \ldots, r\}$ 和 $\{r+1, \ldots, n\}$ 两组。

关键事实：

  • 边数 $m = n$（不再是 $n-1$，因为多了首尾连接）
  • 所有节点度都是 2：$k_i = 2, \forall i$

模块度公式：

$$Q = \frac{2nr - 2r^2 - 2n}{2n^2}$$

最优 $r$：同样对 $r$ 求导，$\frac{dQ}{dr} = \frac{2n - 4r}{2n^2} = 0 \Rightarrow r = \frac{n}{2}$。也就是说，环图也是从正中间切最好。

第二部分 · 考点梳理

重要度：★★★ 高频 ★★ 中等 ★ 低频　　 分类：🧠 记忆 💡 理解/计算

📍 章节 1：社团的概念

考点 1.1　社团（Community）的定义 ★★★ 记忆

定义：网络中一组节点，它们之间内部连接密集（densely connected within），与网络其他部分连接稀疏（sparsely connected between）。

易混点：

  • 不要把社团和 k-core 混淆。k-core 强调"每个节点至少有 k 个邻居在集合内"，是结构性指标；社团强调"内密外疏"。
  • 不要和 聚类系数 混淆。聚类系数衡量"邻居之间是不是互相认识"，是局部三角形密度。

考点 1.2　社团检测的目标 ★★ 记忆

把网络划分为若干节点集合（社团），组内连接密集，组间连接稀疏。

考点 1.3　社团检测 vs 其他网络分析工具 ★ 理解

中心性 → 单点；聚类系数 → 节点 + 直接邻居；k-core → 嵌套的密度；社团 → 全局结构性子集。

📍 章节 2：模块度函数

考点 2.1　Kronecker delta 的含义 ★★★ 记忆

定义 $\delta_{g_ig_j} = 1$ 当 $g_i = g_j$（节点 $i, j$ 同组），$\delta_{g_ig_j} = 0$ 否则。

作用：把"是否同组"嵌入求和——同组的项才被计入，跨组的项贡献为 0。

考点 2.2　实际同组边数 $Q_1$ ★★★ 理解

$$Q_1 = \sum_{\text{edge}(i,j)} \delta_{g_ig_j} = \frac{1}{2}\sum_{i,j} A_{ij}\,\delta_{g_ig_j}$$

易错：前者的求和是"每条边算一次"（无序对），后者是"$i,j$ 双重求和会把每条边数两次"，所以多了 $\frac{1}{2}$。

考点 2.3　随机网络中期望同组边数 $Q_2$ ★★★ 理解

$$Q_2 = \frac{1}{2}\sum_{i,j} \frac{k_ik_j}{2m}\,\delta_{g_ig_j}$$

$\frac{k_ik_j}{2m}$ 是 保度数随机模型 中 $i, j$ 之间的期望连边数。

易错：不要把分母 $2m$ 写成 $m$；不要忘记前面的 $\frac{1}{2}$。

考点 2.4　模块度函数 $Q$ 的定义 ★★★ 记忆 理解

$$Q = \frac{1}{2m}(Q_1 - Q_2) = \frac{1}{2m}\sum_{i,j}\left(A_{ij} - \frac{k_ik_j}{2m}\right)\delta_{g_ig_j}$$

各项物理意义：

  • $\frac{1}{2m}$：标准化因子（不同规模网络可比较）
  • $A_{ij}$：实际是否相连
  • $\frac{k_ik_j}{2m}$：随机模型下的期望连接数
  • $\delta_{g_ig_j}$：只考虑同组对
⚠️ 常见错误
  • 把 $2m$ 写成 $m$
  • 遗漏 $\delta_{g_ig_j}$
  • 把"组数"错当成 $2m$ 的某种除数

考点 2.5　模块度矩阵 $B$ ★★ 记忆

定义 $B_{ij} = A_{ij} - \frac{k_ik_j}{2m}$，则 $Q = \frac{1}{2m}\sum_{i,j} B_{ij}\delta_{g_ig_j}$。

性质：$\sum_j B_{ij} = 0 = \sum_i B_{ij}$（每行每列和为 0）。这是 谱模块度最大化 的出发点。

考点 2.6　模块度最大化原理 ★★ 理解

"好"的分组使组内边数 显著多于 随机模型预期，即 $Q$ 越大越好。理论上枚举所有分组挑 $Q$ 最大者，但 $2^n$ 太多，需用启发式。

📍 章节 3：线图模块度（重点）

考点 3.1　线图基本量 ★★★ 记忆

  • 边数 $m = n - 1$
  • 端点度 $k_1 = k_n = 1$
  • 中间节点度 $k_i = 2$（$2 \le i \le n-1$）

考点 3.2　线图二分模块度公式 ★★★ 记忆 推导

$$Q = \frac{3 - 4n + 4nr - 4r^2}{2(n-1)^2}$$

其中切第 $r$ 条边把网络分为 $r$ 节点和 $n-r$ 节点两段。

推导关键步骤：

  1. $Q_1$ 部分：左段有 $r-1$ 条边，右段有 $n-r-1$ 条边，所以 $Q_1 = \frac{n-2}{n-1}$。
  2. $Q_2$ 部分：左段度数和 $= 2(r-1) + 1 = 2r-1$；右段度数和 $= 2(n-r-1) + 1 = 2(n-r)-1$。$\sum_{ij}k_ik_j\delta_{g_ig_j} = (2r-1)^2 + (2(n-r)-1)^2$。
  3. 代入 $Q_2 = \frac{(2r-1)^2 + (2(n-r)-1)^2}{4(n-1)^2}$，化简。
  4. $Q = Q_1 - Q_2$，化简得最终公式。

考点 3.3　最优切点 ★★★ 计算

$$\frac{dQ}{dr} = \frac{4n - 8r}{2(n-1)^2} = 0 \Rightarrow r = \frac{n}{2}$$

二阶导 $= \frac{-8}{2(n-1)^2} < 0$，确认极大值。

  • $n$ 偶数：$r = n/2$ 即为答案。
  • $n$ 奇数：$r$ 须为整数，最优在 $r = \frac{n-1}{2}$ 或 $\frac{n+1}{2}$（两个对称解，Q 相同）。
⚠️ 易错 忘记奇偶讨论；忘记验证二阶导。

📍 章节 4：环图模块度（习题）

考点 4.1　环图基本量 ★★ 记忆

  • 边数 $m = n$（不是 $n-1$）
  • 所有节点度 $k_i = 2$

考点 4.2　环图二分模块度公式 ★★ 推导

$$Q = \frac{2nr - 2r^2 - 2n}{2n^2}$$

切两条对称的边把环分成 $\{1,\dots,r\}$ 和 $\{r+1,\dots,n\}$。

推导提示：

  1. $Q_1$：每段是路径，左段 $r-1$ 条边，右段 $n-r-1$ 条边，加上切掉的两条边外的所有内部边——其实左段是 $r$ 个节点的路径有 $r-1$ 条边，右段 $n-r-1$ 条；不再赘述。
  2. $Q_2$：每个节点度都是 2，所以每段度数和都是 $2r$ 和 $2(n-r)$。$\sum k_ik_j\delta_{g_ig_j} = (2r)^2 + (2(n-r))^2 = 4r^2 + 4(n-r)^2$。
  3. $m = n$，最终化简得公式。

考点 4.3　环图最优切点 ★★ 计算

求导 $\frac{dQ}{dr} = \frac{2n - 4r}{2n^2} = 0 \Rightarrow r = \frac{n}{2}$。

与线图结论一致：都是正中间切最好。

📍 章节 5：模块度最大化算法

考点 5.1　为什么需要启发式算法 ★★ 理解

$n$ 节点分 2 群有 $2^n$ 种方式。$n=100$ 已经无法穷举。所以需要 good approximations。

考点 5.2　Node-moving 算法 ★★★ 记忆

关键步骤：

  1. 随机平分两组。
  2. 每"轮"：每个节点计算 $\Delta Q$，挑最大者移动；已移动者本轮不能再动；轮结束于所有节点都被移过一次。
  3. 从本轮所有中间状态中选 Q 最高的作为本轮结果。
  4. 以新分组为起点重复，直到 Q 无法再增加。
⚠️ 易错
  • "已移动节点本轮不能再移动"这条规则容易忘。
  • 每轮 Q 不是单调的——选的是 中间最高 Q，不一定是轮末的状态。

考点 5.3　边介数（Edge Betweenness） ★★★ 记忆

定义 $$x_e = \sum_{\substack{j,k \\ j \ne k}} \frac{\sigma_{jk}(e)}{\sigma_{jk}}$$ $\sigma_{jk}$：$j \to k$ 的最短路径数。$\sigma_{jk}(e)$：其中经过边 $e$ 的最短路径数。

直觉：边介数衡量这条边作为"最短路径桥梁"的重要性。桥梁边的介数显著高于内部边。

考点 5.4　Girvan-Newman 算法 ★★★ 记忆

步骤：计算所有边介数 → 删除介数最高的边 → 重新计算介数 → 删 → … 直到网络分裂。

核心特征：

  • 自顶向下分裂（top-down divisive）
  • 每删一条边都要重新计算所有介数（重要！）
  • 基于"桥梁"识别社团

考点 5.5　Greedy Modularity 算法 ★★ 记忆

步骤：

  1. 每节点单独成社团。
  2. 计算每对社团合并的 $\Delta Q$。
  3. 合并 $\Delta Q$ 最大的一对。
  4. 直到无法再增加 Q。

方向：自底向上凝聚（agglomerative）。与 Girvan-Newman 相反。

考点 5.6　Louvain 算法 ★★★ 记忆 理解

步骤：

  1. 每节点独立成组。
  2. 对每个节点：尝试加入某邻居所在组，若提升 Q 则移动。
  3. 所有节点考虑完后，重复 2，直到 Q 不再增加。
  4. 把当前每组"凝聚"成超级节点，得到新网络。
  5. 在新网络上重复 2–3。
  6. 直到无法再提升 Q，输出结果。

时间复杂度：$O((m+n)\log n)$，非常快。

Karate Club 模块度：0.444904（四个算法中最高）。

考点 5.7　四种算法横向对比 ★★★ 理解

算法方向核心机制速度
Node-moving迭代每轮逐个移节点，挑中间最优慢
Girvan-Newman自顶向下反复删高介数边很慢
Greedy自底向上合并 ΔQ 最大的两组较快
Louvain多层级自底向上节点重组 + 聚合迭代非常快 $O((m+n)\log n)$

Q1. 关于"社团（Community）"的定义，下列说法最准确的是：
  • A. 网络中度数最高的若干节点组成的集合。
  • B. 网络中聚类系数最高的若干节点组成的集合。

选择题 模块度公式 基础
Q2. 模块度函数 $Q = \frac{1}{2m}\sum_{i,j}\left(A_{ij} - \frac{k_ik_j}{2m}\right)\delta_{g_ig_j}$ 中，$\frac{k_ik_j}{2m}$ 表示什么？
  • A. 节点 $i$ 和 $j$ 的度的平均值。
  • B. 在保度数随机重连模型中，节点 $i$ 和 $j$ 之间的期望连边数。
  • C. 节点 $i$ 和 $j$ 之间最短路径的长度。
  • D. 节点 $i$ 和 $j$ 之间所有可能的连接方式数。
显示答案与解析 ▼
✅ 答案：B
解析：这是模块度的核心思想。把网络的边"打散"，每条边视为两根"半边"。所有半边数 = $2m$。$i$ 的某根半边连到 $j$ 的某根半边概率 $\approx \frac{k_j}{2m}$，$i$ 有 $k_i$ 根半边可尝试，所以期望连边数 $\approx \frac{k_ik_j}{2m}$。
⚠️ 这一项是模块度"减去随机基准"的体现，是理解整个公式的关键。
选择题 Kronecker delta 基础
Q3. Kronecker delta $\delta_{g_ig_j}$ 在模块度公式中的作用是：
  • A. 只把同组的 $(i,j)$ 对计入求和，跨组对贡献为 0。
  • B. 表示节点 $i$ 和 $j$ 之间是否相邻。
  • C. 标准化模块度到 [-1, 1] 区间。
  • D. 表示节点 $i$ 和 $j$ 是否在同一最短路径上。
显示答案与解析 ▼
✅ 答案：A
解析：$\delta_{g_ig_j} = 1$ 当 $g_i = g_j$（同组），否则为 0。它充当"同组开关"，把模块度的计算限制在同组对内。B 是邻接矩阵 $A_{ij}$ 的作用，不要混淆。

简答题 模块度公式各项含义 进阶
Q7. 写出模块度函数 $Q$ 的定义，并逐项解释公式中各符号的含义。
显示答案与解析 ▼
✅ 参考答案：

模块度函数定义为：

$$Q = \frac{1}{2m}\sum_{i,j}\left(A_{ij} - \frac{k_ik_j}{2m}\right)\delta_{g_ig_j}$$

各符号含义：

  • $m$：网络的总边数。
  • $\frac{1}{2m}$：标准化因子，使不同规模网络的模块度可比，反映连接的"密度"。
  • $A_{ij}$：邻接矩阵元素，$i, j$ 相连为 1，否则为 0。
  • $k_i, k_j$：节点 $i, j$ 的度。
  • $\frac{k_ik_j}{2m}$：在保度数随机模型中，$i, j$ 之间的期望连边数。
  • $\delta_{g_ig_j}$：Kronecker delta，$g_i = g_j$（同组）时为 1，否则为 0；起"同组开关"作用。

整体逻辑：$Q$ 衡量了 原网络组内边数 减去 随机网络组内期望边数，再标准化。Q 越大，说明分组越显著好于随机。

⚠️ 注意：$\sum_{i,j}$ 会把每条边数两次，所以前面有 $\frac{1}{2m}$ 而不是 $\frac{1}{m}$。
计算题 线图最优切点 进阶
Q8. 对于有 $n = 6$ 个节点的线图，分别计算 $r = 1, 2, 3$ 时的模块度 $Q$，并指出最优切法。
显示答案与解析 ▼
✅ 答案：

用公式 $Q = \frac{3 - 4n + 4nr - 4r^2}{2(n-1)^2}$，代入 $n = 6$：

$$Q = \frac{3 - 24 + 24r - 4r^2}{2 \times 25} = \frac{-21 + 24r - 4r^2}{50}$$
  • $r = 1$：$Q = \frac{-21 + 24 - 4}{50} = \frac{-1}{50} = -0.02$
  • $r = 2$：$Q = \frac{-21 + 48 - 16}{50} = \frac{11}{50} = 0.22$
  • $r = 3$：$Q = \frac{-21 + 72 - 36}{50} = \frac{15}{50} = 0.30$

最优 $r = 3 = n/2$，正中间切，$Q$ 最大为 $0.30$。这与理论结论一致。

⚠️ 注意对称性：$r = 4, 5$ 对应 $r' = n-r = 2, 1$ 的情形，结果相同（公式关于 $r = n/2$ 对称）。

填空题 模块度矩阵 进阶
Q10. 定义模块度矩阵 $B_{ij} = $ ＿＿＿。该矩阵的重要性质是：$\sum_j B_{ij} = $ ＿＿＿ $= \sum_i B_{ij}$。
显示答案与解析 ▼
✅ 答案：$B_{ij} = A_{ij} - \frac{k_ik_j}{2m}$；行/列和均为 $0$。
解析：这个性质是谱模块度最大化方法的出发点。它意味着 $B$ 矩阵的行和与列和都是 0，因此它有一个零特征值，对应"全 1 向量"特征向量——也就是"所有节点放一个组"这种 trivial 分组。
⚠️ 验证：$\sum_j B_{ij} = \sum_j A_{ij} - \sum_j \frac{k_ik_j}{2m} = k_i - \frac{k_i \cdot 2m}{2m} = k_i - k_i = 0$。
简答题 Node-moving 算法 进阶
Q11. 简述 Node-moving 算法的步骤，特别说明"轮（round）"的含义以及为何要采用这种规则。
显示答案与解析 ▼
✅ 参考答案：

步骤：

  1. 把网络节点随机平分为两组。
  2. 开始一"轮"（round）：
  3.   a) 对当前每个节点，计算如果把它移到另一组带来的 $\Delta Q$；
  4.   b) 选 $\Delta Q$ 最大的那个节点，移动它；
  5.   c) 这个节点本轮不能再移动；
  6.   d) 重复 a–c，直到所有节点都被移动过一次（即每个节点被移动恰好一次），本轮结束。
  7. 在本轮所有中间状态中选 $Q$ 最高的分组作为本轮结果。
  8. 以本轮结果为新起点，重复上述过程，直到 $Q$ 无法再提升。

为何"已移动节点不能再移动"？这个规则避免"反复横跳"——某节点移动后又被立即移回，造成局部死循环。强制每个节点每轮只动一次，让算法能跳出局部极小值，在更大的搜索空间中寻找更好的分组方案。

为何"选轮中最高 Q"而不是"轮末状态"？因为每次移动选的是 $\Delta Q$ 最大的合法移动，但当所有"好移动"用完后，后续移动可能 $\Delta Q < 0$，导致轮末 $Q$ 反而下降。所以挑全程的最高点更稳妥。

显示答案与解析 ▼

🔴 综合题

计算题（推导） 线图模块度推导 综合
Q13. 考虑有 $n$ 个节点的线图，沿任意一条边切开使两段分别有 $r$ 和 $n-r$ 个节点。证明： $$Q = \frac{3 - 4n + 4nr - 4r^2}{2(n-1)^2}$$
显示答案与解析 ▼
✅ 详细证明：

第 1 步：列出线图的基本量。

  • 边数 $m = n - 1$
  • $k_1 = k_n = 1$；$k_i = 2$ 对所有 $2 \le i \le n-1$

第 2 步：把 $Q$ 拆成 $Q_1 - Q_2$。注意这里的 $Q_1, Q_2$ 是简化记号：

$$Q_1 = \frac{1}{2m}\sum_{ij} A_{ij}\delta_{g_ig_j}, \quad Q_2 = \frac{1}{4m^2}\sum_{ij}k_ik_j\delta_{g_ig_j}$$

第 3 步：计算 $Q_1$（实际同组边数 / 2m）。

$\sum_{ij} A_{ij}\delta_{g_ig_j}$ 是 组内边数的两倍。

  • 左段（$r$ 个节点的路径）有 $r-1$ 条边。
  • 右段（$n-r$ 个节点的路径）有 $n-r-1$ 条边。

所以 $\sum_{ij} A_{ij}\delta_{g_ig_j} = 2(r-1) + 2(n-r-1) = 2n - 4$。

$$Q_1 = \frac{2(r-1) + 2(n-r-1)}{2(n-1)} = \frac{n-2}{n-1}$$

第 4 步：计算 $\sum_{ij}k_ik_j\delta_{g_ig_j}$。

$\delta_{g_ig_j} = 1$ 当且仅当 $i,j$ 同段。把求和拆成两段：

$$\sum_{ij}k_ik_j\delta_{g_ig_j} = \left(\sum_{i=1}^r k_i\right)^2 + \left(\sum_{i=r+1}^n k_i\right)^2$$

计算左段度数和：左段包含 1 号节点（度 1）和 $2,\ldots,r$ 号节点（每个度 2）。所以：

$\sum_{i=1}^r k_i = 1 + 2(r-1) = 2r - 1$

计算右段度数和：右段包含 $n$ 号节点（度 1）和 $r+1,\ldots,n-1$ 号节点（每个度 2）。所以：

$\sum_{i=r+1}^n k_i = 1 + 2(n-r-1) = 2(n-r) - 1$

代入：

$$\sum_{ij}k_ik_j\delta_{g_ig_j} = (2r-1)^2 + (2(n-r)-1)^2$$

第 5 步：展开化简。

$(2r-1)^2 = 4r^2 - 4r + 1$

$(2(n-r)-1)^2 = 4(n-r)^2 - 4(n-r) + 1 = 4n^2 - 8nr + 4r^2 - 4n + 4r + 1$

相加：

$$= 8r^2 + 4n^2 - 8nr - 4n + 2$$

第 6 步：计算 $Q_2$。

$$Q_2 = \frac{8r^2 + 4n^2 - 8nr - 4n + 2}{4(n-1)^2} = \frac{4r^2 + 2n^2 - 4nr - 2n + 1}{2(n-1)^2}$$

第 7 步：$Q = Q_1 - Q_2$。

把 $Q_1 = \frac{n-2}{n-1}$ 通分成 $\frac{2(n-1)(n-2)}{2(n-1)^2}$，展开 $2(n-1)(n-2) = 2n^2 - 6n + 4$。

$$Q = \frac{2n^2 - 6n + 4 - (4r^2 + 2n^2 - 4nr - 2n + 1)}{2(n-1)^2}$$ $$= \frac{2n^2 - 6n + 4 - 4r^2 - 2n^2 + 4nr + 2n - 1}{2(n-1)^2}$$ $$= \frac{3 - 4n + 4nr - 4r^2}{2(n-1)^2}$$

证毕。 $\blacksquare$

⚠️ 常见错误：① 计算两段度数和时忘了端点度为 1；② 平方展开时漏项；③ 通分时分子符号搞错。
计算题 最优切点求导 综合
Q14. 基于上题结果 $Q = \frac{3 - 4n + 4nr - 4r^2}{2(n-1)^2}$，证明：当 $n$ 为偶数时，最优切点是 $r = n/2$；并讨论 $n$ 为奇数时的情形。
显示答案与解析 ▼
✅ 答案：

第 1 步：对 $r$ 求导。

分母 $2(n-1)^2$ 不含 $r$，只对分子求导：

$$\frac{dQ}{dr} = \frac{1}{2(n-1)^2} \cdot \frac{d}{dr}(3 - 4n + 4nr - 4r^2) = \frac{4n - 8r}{2(n-1)^2}$$

第 2 步：令导数为 0。

$4n - 8r = 0 \Rightarrow r = \frac{n}{2}$。

第 3 步：验证极大值。

$$\frac{d^2Q}{dr^2} = \frac{-8}{2(n-1)^2} = \frac{-4}{(n-1)^2} < 0$$

所以 $r = n/2$ 是极大值。

第 4 步：讨论奇偶。

  • $n$ 为偶数：$r = n/2$ 是整数，可以取到。正中间切就是最优分法。
  • $n$ 为奇数：$r = n/2$ 不是整数。由于公式关于 $r = n/2$ 对称（替换 $r \to n-r$ 公式不变），所以 $r = \frac{n-1}{2}$ 和 $r = \frac{n+1}{2}$ 是 两个对称的整数最优解，给出相同的 $Q$ 值。即左右两段相差 1 个节点的两种切法等价最优。
⚠️ 务必验证二阶导数确认是极大值。考试时若漏了这一步可能扣分。
计算题 环图模块度推导 综合
Q15. 考虑 2-regular ring lattice（环图），$n$ 个节点顺时针编号。把它分为 $\{1, \ldots, r\}$ 和 $\{r+1, \ldots, n\}$ 两个社团。证明： $$Q = \frac{2nr - 2r^2 - 2n}{2n^2}$$ 并求最佳 $r$。
显示答案与解析 ▼
✅ 详细推导：

第 1 步：环图基本量。

  • 边数 $m = n$（每个节点连两个邻居，但每条边算两次：$2n/2 = n$）。
  • 所有节点度 $k_i = 2$。

第 2 步：拆解 $Q = Q_1 - Q_2$。

第 3 步：计算 $Q_1$。

把环切成两段：

  • 左段（节点 $1, \ldots, r$）是一条路径，有 $r-1$ 条内部边。
  • 右段（节点 $r+1, \ldots, n$）是一条路径，有 $n-r-1$ 条内部边。
  • 注意环图有 两条被切的边（连接 $r,r+1$ 和 $n,1$ 的边），它们是跨组的，不算。

组内边总数 $= (r-1) + (n-r-1) = n - 2$。所以：

$$\sum_{ij} A_{ij}\delta_{g_ig_j} = 2(n-2), \quad Q_1 = \frac{2(n-2)}{2n} = \frac{n-2}{n}$$

第 4 步：计算 $\sum k_ik_j\delta_{g_ig_j}$。

因所有 $k_i = 2$：

  • 左段度和 $= 2r$
  • 右段度和 $= 2(n-r)$
$$\sum_{ij}k_ik_j\delta_{g_ig_j} = (2r)^2 + (2(n-r))^2 = 4r^2 + 4(n-r)^2$$

第 5 步：计算 $Q_2$。

$Q_2 = \frac{1}{4m^2}\sum k_ik_j\delta_{g_ig_j} = \frac{4r^2 + 4(n-r)^2}{4n^2} = \frac{r^2 + (n-r)^2}{n^2}$

展开 $(n-r)^2 = n^2 - 2nr + r^2$：

$$Q_2 = \frac{2r^2 - 2nr + n^2}{n^2}$$

第 6 步：$Q = Q_1 - Q_2$。

$Q_1 = \frac{n-2}{n} = \frac{n(n-2)}{n^2} = \frac{n^2 - 2n}{n^2}$。

$$Q = \frac{n^2 - 2n - (2r^2 - 2nr + n^2)}{n^2} = \frac{-2n - 2r^2 + 2nr}{n^2} = \frac{2nr - 2r^2 - 2n}{n^2}$$

题目给出形式分母为 $2n^2$，分子加倍即可：

$$Q = \frac{2nr - 2r^2 - 2n}{2n^2} \cdot \frac{2}{1} \to \frac{4nr - 4r^2 - 4n}{2n^2}$$

这里题目给出的形式 $\frac{2nr - 2r^2 - 2n}{2n^2}$ 可以化简为 $\frac{nr - r^2 - n}{n^2}$，与上面的 $\frac{2nr - 2r^2 - 2n}{2n^2}$ 相同。我们的结果 $\frac{2nr - 2r^2 - 2n}{n^2}$ 比题目结果大 2 倍。重新检验：题目分母 $2n^2$，分子 $2nr - 2r^2 - 2n$，化简 $= \frac{nr - r^2 - n}{n^2}$。我们的结果 $\frac{2nr - 2r^2 - 2n}{n^2} = \frac{2(nr - r^2 - n)}{n^2}$，确实有 2 倍差异。原因可能在于：

核对：实际同组边数应该是 $r-1 + n-r-1 = n-2$，所以 $Q_1 = \frac{(n-2)}{n}$（不带 2，因为 $\sum A_{ij}$ 双重求和数两遍，所以除以 2m = 2n，$2(n-2)/(2n) = (n-2)/n$，没问题）。$Q_2 = \frac{2r^2 - 2nr + n^2}{n^2}$。差 $= \frac{(n^2-2n) - (2r^2-2nr+n^2)}{n^2} = \frac{-2n -2r^2 + 2nr}{n^2}$。该结果与题目相差 2 倍。原题课件公式为 $\frac{2nr-2r^2-2n}{2n^2}$。检验：把分子分母同除 2 得 $\frac{nr-r^2-n}{n^2}$，我们的是 $\frac{2nr-2r^2-2n}{n^2}$，差 2 倍。这可能是讲义公式定义的细微差异（如某些项约定）。但最重要的是分子结构和最优 $r$ 的位置正确。

第 7 步：求最优 $r$（无论分母 2 倍差异）。

对分子 $f(r) = 2nr - 2r^2 - 2n$ 求导：$f'(r) = 2n - 4r = 0 \Rightarrow r = n/2$。

二阶导 $f''(r) = -4 < 0$，确认极大值。

最优切点 $r = n/2$（偶数时取整数；奇数时取 $\frac{n-1}{2}$ 或 $\frac{n+1}{2}$）。结论与线图一致。

⚠️ 推导环图时务必记得：① 边数是 $n$ 不是 $n-1$；② 切环图实际切 2 条边（首尾相接的那条不要忘）；③ 所有节点度为 2，简化了 $\sum k_ik_j$ 的计算。
论述题 综合理解 综合
Q16. 综合论述：从"为什么需要模块度"开始，依次说明 (a) 模块度函数的设计思想；(b) 直接最大化模块度面临的困难；(c) 至少两种启发式算法的核心思路；(d) 它们的优缺点。
显示答案与解析 ▼
✅ 参考答案要点：

（a）模块度函数的设计思想

社团检测的本质问题是：给一个分组方案打分。直觉是"组内边多、组间边少"就好，但仅看绝对边数不公平——节点度高的网络组内边自然多。所以构造对照：

  • 把原网络的边"打散"，保持每个节点度不变；
  • 在这个"保度数随机模型"下，节点 $i, j$ 间的期望连边数是 $\frac{k_ik_j}{2m}$；
  • 把"实际同组边数 减 随机模型同组期望边数"作为分数，再用 $\frac{1}{2m}$ 标准化。

这就是 $Q = \frac{1}{2m}\sum_{ij}(A_{ij} - \frac{k_ik_j}{2m})\delta_{g_ig_j}$。Q 越大，说明分组组内的"超额边数"越多，方案越好。

（b）直接最大化的困难

n 个节点的二分方案有 $2^n$ 种，更不要说允许多个社团或不等大小。对 $n = 100$ 已经 $\approx 10^{30}$ 种，穷举完全不可行。实际上模块度最大化在一般情况下是 NP-hard 问题。所以必须用 启发式算法 找近似最优解。

（c）几种启发式算法的核心思路

  • Node-moving：从随机二分开始，每轮逐个移动 ΔQ 最大的节点，已动者不再动，挑全轮最优 Q 作为下一轮起点。直到无法提升。
  • Girvan-Newman：自顶向下。反复删除边介数最高的边（即"桥梁边"），网络逐步分裂成多个连通分量。每删一边都要重算介数。
  • Greedy Modularity：自底向上。每个节点单独成组，反复合并 ΔQ 最大的两个社团，直到无法提升 Q。
  • Louvain：自底向上多层级。先节点层做局部 ΔQ 提升的移动；然后把当前社团"凝聚"为超级节点，在新网络上重复；直到 Q 无法再增加。

（d）优缺点对比

算法优点缺点
Node-moving简单直观；有"已移则锁"避免局部死循环慢；初始化随机，结果可能不稳定
Girvan-Newman层级化结果，可看不同分辨率的社团非常慢（每步重算所有边介数 $O(mn)$ 或更高）
Greedy较快；自动确定社团数贪婪策略可能错过更好的全局解
Louvain非常快 $O((m+n)\log n)$；通常质量最高（Karate 上 Q = 0.444904 居首）；可处理百万级网络每次运行结果可能不同；存在"分辨率限制"（resolution limit）问题，可能合并不该合并的小社团

总结：在实际中，Louvain 是工业级首选；Girvan-Newman 多用于教学和小网络的层级分析；Node-moving 和 Greedy 用于理论教学或特殊场景。所有这些方法都依赖模块度这一统一评分标准，但因模块度本身存在分辨率限制等问题，近年也有 Map Equation、SBM 等替代方法发展。

计算题 边介数 综合
Q17. 写出边介数的数学定义；并解释为什么 Girvan-Newman 算法选择"删除介数最高的边"作为划分社团的策略。
显示答案与解析 ▼
✅ 答案：

边介数定义：

$$x_e = \sum_{\substack{j,k \\ j \ne k}} \frac{\sigma_{jk}(e)}{\sigma_{jk}}$$

其中 $\sigma_{jk}$ 表示从节点 $j$ 到 $k$ 的最短路径总数，$\sigma_{jk}(e)$ 表示其中经过边 $e$ 的最短路径数。

为何 Girvan-Newman 选高介数边？

社团之间通常只靠少数"桥梁边"相连。考虑一个典型情形：

  • 社团 A 有 $n_A$ 个节点，社团 B 有 $n_B$ 个节点；
  • A、B 之间只有一条桥梁边 $e$；
  • 那么任何 A 中节点到 B 中节点的最短路径都必须经过 $e$；
  • 共有 $n_A \times n_B$ 对这样的最短路径，每对最短路径都贡献 1（如果唯一）；
  • 所以 $x_e \ge n_A \times n_B$，是个很大的数；
  • 相比之下，社团内部的边只承载本社团内的最短路径，介数小得多。

因此，边介数能识别社团之间的"桥梁"。删除介数最高的边等于"切断桥梁"，自然把网络分裂成社团。每删一条边都需要重新计算介数，因为最短路径可能发生改变。

⚠️ 易错：① 公式中分母是"总最短路径数"，分子是"经过 $e$ 的最短路径数"，不要写反；② 不要忘记 $j \ne k$ 的条件；③ 关于求和指标 $j, k$，多数定义下是有序对（即 $(j,k)$ 和 $(k,j)$ 都数），在无向图中本质相同。
简答题 Louvain 算法 综合
Q18. 详细描述 Louvain 算法的步骤。说明它为什么被称为"多层级"算法，以及它的时间复杂度。
显示答案与解析 ▼
✅ 参考答案：

Louvain 算法步骤：

第一阶段（局部移动）：

  1. 初始时，每个节点单独成一个社团。
  2. 对每个节点 $i$，依次考察它的每个邻居：如果把 $i$ 加入该邻居所在的社团能 提升模块度（ΔQ > 0），则把 $i$ 移过去；移到能带来最大 ΔQ 的社团。如果没有任何移动能提升 Q，$i$ 保持原状。
  3. 所有节点都考察一遍后，重复步骤 2，直到一轮中没有任何节点移动（局部最优）。

第二阶段（聚合）：

  1. 把第一阶段得到的每个社团 "凝聚"为一个超级节点。新网络中，超级节点之间的边权 = 原社团之间所有边的权重之和（含原社团内部的边变成自环）。
  2. 在这个新网络上重复第一阶段（步骤 1–3）：每个超级节点尝试加入邻居超级节点所在的"超级社团"。

循环：

  1. 第一阶段和第二阶段交替进行，直到再也无法提升 Q，输出当前的社团划分。

为何"多层级"？

算法每轮都把"上一轮的社团"作为"下一轮的基本单元"，形成层级结构。第一轮在节点层面找小社团，第二轮在小社团之间找"小社团的社团"，依此类推。这种 hierarchical 结构能自然处理网络中存在的多尺度社团（比如"班级 → 年级 → 学校"）。

时间复杂度：$O((m+n)\log n)$，是已知社团检测算法中最快的之一。可处理百万级节点的网络。

性能：在 Karate Club 上达到模块度 0.444904，是课件提及的四种算法中最高。

⚠️ 易错：① 把"凝聚阶段"忽略，只说节点层面的移动，那只是 Greedy 风格而不是 Louvain；② 不要把 Louvain 复杂度写成 $O(n \log n)$ 或 $O(n^2)$。
