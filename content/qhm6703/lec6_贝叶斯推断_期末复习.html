第一部分：课程内容讲解

整体知识脉络

这节课的核心问题是：当我们观测到一组服从正态分布的数据，但不知道均值 $\mu$ 时，怎样用贝叶斯方法来推断 $\mu$？

整体逻辑链条如下：

为什么用正态分布？（中心极限定理 CLT） 许多实际数据可以用正态分布来建模，因为 CLT 告诉我们：大量独立随机变量的和（或均值）近似服从正态分布。
贝叶斯推断的框架 先验 (Prior) → 数据/似然 (Likelihood) → 后验 (Posterior)。
本节聚焦于：$\mu$ 取离散有限个值时的贝叶斯推断。
从简到繁 先处理单个观测值的情况，再推广到多个观测值（随机样本）的情况。

1. 中心极限定理 (CLT)

中心极限定理指出：不管原始随机变量服从什么分布，只要它们独立且具有有限方差，大量这样的随机变量之和（或均值）的分布就会趋向正态分布。

类比理解：想象你掷一个骰子，结果是均匀分布的（1~6）。但如果你同时掷 100 个骰子并求它们的平均值，这个平均值的分布就会非常接近正态分布——这就是 CLT 的威力。

正因为如此，正态分布成为统计建模中最广泛使用的分布。

2. 正态分布的基本性质

随机变量 $X \sim N(\mu, \sigma^2)$ 的概率密度函数 (PDF) 为：

$$p(x \mid \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2\right), \quad -\infty < x < \infty$$

关键性质：

对称性：正态分布关于 $\mu$ 对称，$\mu$ 同时是均值、中位数和众数。
95% 区间：约 95% 的数据落在 $[\mu - 1.96\sigma,\ \mu + 1.96\sigma]$ 区间内。

3. 单个观测值的贝叶斯推断

假设只有一个数据点 $Y_1 \sim N(\mu, \sigma_0^2)$，其中方差 $\sigma_0^2$ 已知，$\mu$ 未知。

3.1 离散先验

假设 $\mu$ 只可能取有限个值 $\mu_1, \mu_2, \ldots, \mu_m$。我们为每个值赋一个先验概率：

$$p(\mu = \mu_i) = c_i, \quad \text{其中 } \sum_{i=1}^{m} c_i = 1$$

如果对 $\mu$ 一无所知，可以选离散均匀先验，即 $c_i = 1/m$。

3.2 似然函数

似然函数是"在给定 $\mu$ 的条件下，观测到 $Y_1 = y_1$ 的概率"：

$$L(\mu \mid Y_1) \propto \exp\left(-\frac{1}{2}\left(\frac{y_1 - \mu}{\sigma_0}\right)^2\right)$$
注意：似然函数是关于 $\mu$ 的函数，$y_1$ 和 $\sigma_0$ 都是已知常数。我们把 $\mu$ 代入不同的取值来计算各自的似然。

3.3 后验分布

根据贝叶斯定理，后验概率为：

$$p(\mu_j \mid Y_1) = \frac{p(Y_1 \mid \mu_j)\, p(\mu_j)}{\sum_{i=1}^{m} p(Y_1 \mid \mu_i)\, p(\mu_i)} = \frac{\text{似然} \times \text{先验}}{\sum (\text{似然} \times \text{先验})}$$
课件例题：$Y_1 = 3.2$，$\sigma_0^2 = 1$，$\mu \in \{2.0, 2.5, 3.0, 3.5, 4.0\}$，均匀先验（各 0.2）。

计算步骤：对每个 $\mu_j$，计算 $e^{-\frac{1}{2}(3.2 - \mu_j)^2}$，乘以先验 0.2，再归一化。结果显示 $\mu = 3.0$ 获得最高后验概率 (0.2493)，因为 $3.0$ 最接近观测值 $3.2$。

4. 随机样本（多个观测值）的贝叶斯推断

当有 $n$ 个独立同分布的观测 $Y_1, \ldots, Y_n \sim N(\mu, \sigma_0^2)$ 时，推断变得更强大。

4.1 联合似然函数

由于各观测独立，联合似然是各个似然的乘积：

$$L(\mu \mid Y) = \prod_{i=1}^n L(\mu \mid Y_i) \propto \exp\left(-\frac{n}{2\sigma_0^2}(\bar{y} - \mu)^2\right)$$

其中 $\bar{y} = \frac{1}{n}\sum_{i=1}^n y_i$ 是样本均值。

关键简化：多个观测值的似然函数只依赖于样本均值 $\bar{y}$ 和 样本量 $n$，无需逐个处理每个数据点！$\bar{y}$ 是 $\mu$ 的充分统计量。

4.2 后验分布

$$p(\mu_j \mid Y) = \frac{p(Y \mid \mu_j)\, p(\mu_j)}{\sum_{i=1}^{m} p(Y \mid \mu_i)\, p(\mu_i)}$$

4.3 两种等价方法

方法 A（一次性处理）：直接用所有数据计算联合似然，然后乘以先验做归一化。
方法 B（逐步更新）：先用 $Y_1$ 做一次贝叶斯更新得到后验；把这个后验作为新的先验，再用 $Y_2$ 更新……依次进行到 $Y_n$。两种方法结果完全一致。
课件例题：$Y_1=3.2, Y_2=2.2, Y_3=3.6, Y_4=4.1$，$\sigma_0^2=1$，$\bar{y}=3.275$，$\mu \in \{2.0, 2.5, 3.0, 3.5, 4.0\}$。

似然中指数部分为 $e^{-\frac{4}{2 \times 1}(3.275 - \mu)^2} = e^{-2(3.275 - \mu)^2}$。
结果：$\mu = 3.5$ 获得最高后验 (0.3685)。与仅用单个 $Y_1=3.2$ 相比，4 个数据点让后验分布更"尖锐"（更集中），不确定性更小。

5. 更多数据 → 更精确的推断

课件强调了一个重要现象：随着数据量增加，后验分布变得越来越集中在真正的 $\mu$ 附近。例如：

对比：仅用 $Y_1 = 3.2$ 时，$p(\mu=2 \mid Y_1) = 0.1238$（还有一定可能性）。
使用全部 4 个数据后，$p(\mu=2 \mid Y) = 0.0157$（可能性大幅下降）。
更多的数据让后验越来越由数据主导，先验的影响逐渐减弱。

6. 习题涉及的扩展内容（Problem Sheet）

习题表不仅涉及正态分布，还涉及泊松分布和二项分布的贝叶斯推断，这些是之前课程的重要内容：

泊松-伽马共轭：泊松似然 + Gamma 先验 → Gamma 后验。
二项-贝塔共轭：二项似然 + Beta 先验 → Beta 后验。
离散先验 / 均匀先验：任何似然函数都可以搭配离散先验使用贝叶斯定理。

第二部分：考点梳理

考点 1：中心极限定理 (CLT)

定义：大量独立随机变量的和（或均值）近似服从正态分布，无论原始分布是什么（只需有限方差）。
意义：解释了正态分布为何是最常用的数据模型。
需要理解 ★★

易混淆点：CLT 描述的是均值/和的分布趋向正态，而不是说原始数据本身一定是正态的。

考点 2：正态分布的 PDF 及基本性质

PDF：$p(x \mid \mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{1}{2}\left(\frac{x-\mu}{\sigma}\right)^2\right)$
关键性质：① 关于 $\mu$ 对称；② $\mu$ = 均值 = 中位数 = 众数；③ 95% 数据在 $\mu \pm 1.96\sigma$ 内。
需要记忆 需要理解 ★★

常见错误：混淆标准差 $\sigma$ 和方差 $\sigma^2$，在似然计算中代错。

考点 3：离散先验的设定

定义：$p(\mu = \mu_i) = c_i$，$\sum c_i = 1$。离散均匀先验：$c_i = 1/m$。
适用场景：$\mu$ 只可能取有限个已知值时使用。
需要记忆 ★★★

易混淆点："均匀先验"指每个值概率相等，不等于"$\mu$ 可以取任何值"。

考点 4：单个观测的似然函数 ★★★

公式：$L(\mu \mid Y_1) \propto \exp\left(-\frac{1}{2}\left(\frac{y_1 - \mu}{\sigma_0}\right)^2\right)$
核心理解：似然是关于 $\mu$ 的函数（$y_1, \sigma_0$ 是常数），可忽略与 $\mu$ 无关的常数因子。
需要计算 ★★★

常见错误：① 忘记似然是 $\mu$ 的函数（把 $y_1$ 当变量）；② 把 $\sigma_0^2$ 和 $\sigma_0$ 搞混（指数中分母是 $\sigma_0$）。

考点 5：单个观测的后验分布计算 ★★★

公式：$p(\mu_j \mid Y_1) = \frac{p(Y_1 \mid \mu_j)\, p(\mu_j)}{\sum_{i=1}^{m} p(Y_1 \mid \mu_i)\, p(\mu_i)}$
计算步骤：① 计算每个 $\mu_j$ 的似然值；② 乘以先验；③ 求和（分母）；④ 归一化。
需要计算 ★★★

易错提醒：归一化步骤不能省略——分母是所有 (先验 × 似然) 的总和，不是某一项。

考点 6：随机样本的似然函数（样本均值的作用） ★★★

公式：$L(\mu \mid Y) \propto \exp\left(-\frac{n}{2\sigma_0^2}(\bar{y} - \mu)^2\right)$，其中 $\bar{y} = \frac{1}{n}\sum y_i$
核心要点：联合似然只通过 $\bar{y}$ 和 $n$ 来影响后验。$\bar{y}$ 是充分统计量。
需要计算 需要理解 ★★★

常见错误：指数中分母是 $\frac{2\sigma_0^2}{n}$（即 $\sigma_0^2/n$ 的 2 倍），不是 $2\sigma_0^2$。注意 $n$ 出现在分子而非分母。

考点 7：随机样本的后验分布计算 ★★★

公式：同考点 5 的结构，但用联合似然代替单次似然。
步骤总结：① 计算 $\bar{y}$；② 用联合似然公式计算每个 $\mu_j$ 的似然；③ 乘以先验；④ 归一化。
需要计算 ★★★

考点 8：逐步更新 vs 一次性处理

等价性：可以逐个观测更新（上一次的后验变下一次的先验），也可以一次性用全部数据更新，结果相同。
需要理解 ★★

考点 9：数据量对后验的影响

核心结论：数据越多 → 后验越集中 → 先验影响越小 → 推断越精确。
需要理解 ★★

考点 10：泊松-伽马共轭（Problem Sheet 延伸）

共轭关系：若 $Y_i \sim \text{Poisson}(\mu)$，先验 $\mu \sim \text{Gamma}(\alpha, \beta)$，则后验 $\mu \mid Y \sim \text{Gamma}(\alpha + \sum y_i,\ \beta + n)$。
需要记忆 需要计算 ★★★

考点 11：二项-贝塔共轭（Problem Sheet 延伸）

共轭关系：若 $Y \sim \text{Binomial}(n, \theta)$，先验 $\theta \sim \text{Beta}(\alpha, \beta)$，则后验 $\theta \mid Y \sim \text{Beta}(\alpha + \sum y_i,\ \beta + n - \sum y_i)$。
需要记忆 需要计算 ★★★

考点 12：均匀先验与"后验 ∝ 似然"

核心思想：当先验为均匀分布 $p(\mu) = \text{constant}$ 时，后验正比于似然：Posterior $\propto$ Likelihood。
应用：对泊松数据用均匀先验，后验为 Gamma 分布。
需要理解 需要计算 ★★

Q1 选择题 基础 考点 1: CLT

中心极限定理 (CLT) 的核心含义是什么？

  • A. 任何随机变量本身都服从正态分布
  • B. 正态分布的均值等于中位数
  • C. 大量独立随机变量的和（或均值）近似服从正态分布
  • D. 样本量越大，方差越大
显示答案与解析 ▼

正确答案：C

解析：CLT 说的是和/均值的分布趋向正态，而非原始变量本身。选项 A 混淆了这一点；B 是正态分布的性质但不是 CLT 的含义；D 完全错误。

Q2 选择题 基础 考点 4: 似然函数

对于 $Y_1 \sim N(\mu, \sigma_0^2)$，似然函数 $L(\mu \mid Y_1)$ 是关于哪个变量的函数？

  • A. $Y_1$
  • B. $\mu$
  • C. $\sigma_0^2$
  • D. $Y_1$ 和 $\mu$
显示答案与解析 ▼

正确答案：B

解析：似然函数的本质是"固定数据，让参数变化"。在这里 $y_1$ 和 $\sigma_0^2$ 都是已知常数，唯一变化的量是 $\mu$。这是非常核心的概念。

Q3 判断题 基础 考点 8: 逐步更新

判断：对于 $n$ 个独立同分布正态观测，使用"逐步更新"（每次用一个数据点）和"一次性使用全部数据"得到的后验分布是不同的。

  • A. 正确
  • B. 错误
显示答案与解析 ▼

正确答案：B（错误）

解析：两种方法得到的后验分布完全相同。逐步更新时，每一步的后验变成下一步的先验，最终结果与一次性使用全部数据等价。这是贝叶斯更新的重要性质。

Q4 选择题 进阶 考点 6: 随机样本似然

$Y_1, \ldots, Y_n \sim N(\mu, \sigma_0^2)$ 的联合似然函数可以化简为只依赖于哪些统计量？

  • A. 所有个体观测值 $y_1, \ldots, y_n$
  • B. 样本方差 $s^2$
  • C. 样本均值 $\bar{y}$ 和样本量 $n$
  • D. 样本中位数和样本量 $n$
显示答案与解析 ▼

正确答案：C

解析：$L(\mu \mid Y) \propto \exp\left(-\frac{n}{2\sigma_0^2}(\bar{y} - \mu)^2\right)$，只包含 $\bar{y}$ 和 $n$。$\bar{y}$ 是 $\mu$ 的充分统计量，它"足以"概括全部数据对 $\mu$ 的信息。

Q5 计算题 进阶 考点 4, 5: 单次观测后验

（Problem Sheet Q1a）设有 $Y \sim N(\mu, \sigma_0^2 = 0.25^2 = 0.0625)$，观测到 $Y_1 = 4.72$。$\mu$ 的可能取值为 $\{4, 5\}$，先验均匀（各 0.5）。求后验分布 $p(\mu \mid Y_1)$。

显示答案与解析 ▼

解题步骤：

Step 1：确定参数
$y_1 = 4.72$，$\sigma_0 = 0.25$，先验 $p(\mu=4) = p(\mu=5) = 0.5$
Step 2：计算各 $\mu$ 的似然
$L(\mu=4 \mid Y_1) \propto e^{-\frac{1}{2}\left(\frac{4.72-4}{0.25}\right)^2} = e^{-\frac{1}{2}(2.88)^2} = e^{-4.1472} \approx 0.01588$

$L(\mu=5 \mid Y_1) \propto e^{-\frac{1}{2}\left(\frac{4.72-5}{0.25}\right)^2} = e^{-\frac{1}{2}(-1.12)^2} = e^{-0.6272} \approx 0.5340$
Step 3：先验 × 似然
$\mu=4$：$0.5 \times 0.01588 = 0.00794$
$\mu=5$：$0.5 \times 0.5340 = 0.2670$
求和：$0.00794 + 0.2670 = 0.27494$
Step 4：归一化得后验
$p(\mu=4 \mid Y_1) = \frac{0.00794}{0.27494} \approx \boxed{0.0289}$

$p(\mu=5 \mid Y_1) = \frac{0.2670}{0.27494} \approx \boxed{0.9711}$

结论：观测值 4.72 更接近 5，所以后验强烈倾向于 $\mu = 5$。

⚠️ 易错：$\sigma_0 = 0.25$（标准差），不是 $\sigma_0^2 = 0.0625$（方差），似然公式中分母是 $\sigma_0$！

Q6 计算题 综合 考点 6, 7: 随机样本后验

（Problem Sheet Q1b）在 Q5 的设定下，现在使用全部 5 个数据点：$4.72, 5.19, 4.81, 4.87, 4.88$。求后验分布 $p(\mu \mid Y)$。

显示答案与解析 ▼
Step 1：计算样本均值
$\bar{y} = \frac{4.72 + 5.19 + 4.81 + 4.87 + 4.88}{5} = \frac{24.47}{5} = 4.894$
Step 2：确定似然公式参数
$n = 5$，$\sigma_0^2 = 0.0625$
$\frac{n}{2\sigma_0^2} = \frac{5}{2 \times 0.0625} = \frac{5}{0.125} = 40$
所以 $L(\mu \mid Y) \propto e^{-40(\bar{y} - \mu)^2}$
Step 3：计算各 $\mu$ 的似然
$\mu=4$：$e^{-40(4.894-4)^2} = e^{-40 \times 0.7992} = e^{-31.97} \approx 1.57 \times 10^{-14}$
$\mu=5$：$e^{-40(4.894-5)^2} = e^{-40 \times 0.01124} = e^{-0.4494} \approx 0.6380$
Step 4：先验 × 似然，归一化
$\mu=4$：$0.5 \times 1.57 \times 10^{-14} \approx 7.85 \times 10^{-15}$（几乎为零）
$\mu=5$：$0.5 \times 0.6380 = 0.3190$
求和 $\approx 0.3190$
后验：
$p(\mu=4 \mid Y) \approx \boxed{0.0000}$（实际为 $2.46 \times 10^{-14}$）
$p(\mu=5 \mid Y) \approx \boxed{1.0000}$

分析：5 个数据点的均值为 4.894，非常接近 5，远离 4。因此后验几乎 100% 确定 $\mu = 5$。对比 Q5（仅用一个数据点时还有约 3% 的概率给 $\mu=4$），多数据点大幅增强了推断的确定性。

Q7 计算题 进阶 考点 10: 泊松-伽马共轭

（Problem Sheet Q2a）有 5 个来自 $\text{Poisson}(\mu)$ 的观测：$3, 4, 3, 0, 1$。先验为 $\text{Gamma}(1, 1)$。求后验分布。

显示答案与解析 ▼
共轭公式：先验 $\text{Gamma}(\alpha, \beta)$ + 泊松数据 → 后验 $\text{Gamma}(\alpha + \sum y_i, \ \beta + n)$
代入：
$\sum y_i = 3 + 4 + 3 + 0 + 1 = 11$，$n = 5$
$\alpha' = 1 + 11 = 12$，$\beta' = 1 + 5 = 6$

后验：$\mu \mid Y \sim \boxed{\text{Gamma}(12,\ 6)}$

后验均值：$E[\mu \mid Y] = \alpha'/\beta' = 12/6 = 2$

⚠️ 注意 Gamma 分布的参数化：这里用的是 $\text{Gamma}(\text{shape}, \text{rate})$，不是 $(\text{shape}, \text{scale})$。

Q8 计算题 综合 考点 5（泊松版）: 离散先验后验

（Problem Sheet Q2b）同 Q7 的数据（泊松观测 3,4,3,0,1），先验改为离散：$p(\mu=3)=0.6$，$p(\mu=4)=0.4$。求后验。

显示答案与解析 ▼
Step 1：泊松联合似然
$L(\mu \mid Y) \propto e^{-n\mu} \cdot \mu^{\sum y_i} = e^{-5\mu} \cdot \mu^{11}$
Step 2：代入各 $\mu$
$\mu=3$：$e^{-15} \times 3^{11} = 3.059 \times 10^{-7} \times 177147 \approx 0.05419$
$\mu=4$：$e^{-20} \times 4^{11} = 2.061 \times 10^{-9} \times 4194304 \approx 0.008647$
Step 3：先验 × 似然
$\mu=3$：$0.6 \times 0.05419 = 0.03251$
$\mu=4$：$0.4 \times 0.008647 = 0.003459$
求和：$0.03597$
Step 4：归一化
$p(\mu=3 \mid Y) = \frac{0.03251}{0.03597} \approx \boxed{0.9039}$

$p(\mu=4 \mid Y) = \frac{0.003459}{0.03597} \approx \boxed{0.0961}$

解读：样本均值 $\bar{y} = 11/5 = 2.2$，比 3 和 4 都小，但 3 更接近。加上先验本身就偏向 3（60%），后验更确定 $\mu = 3$。

Q9 计算题 综合 考点 12: 均匀先验

（Problem Sheet Q2c）同 Q7 的数据，先验改为均匀先验 $p(\mu) = 1$，$\mu > 0$。求后验分布。

显示答案与解析 ▼
关键思路：均匀先验意味着后验 ∝ 似然
$p(\mu \mid Y) \propto L(\mu \mid Y) \times p(\mu) = L(\mu \mid Y) \times 1 = L(\mu \mid Y)$
泊松似然：
$L(\mu \mid Y) \propto e^{-5\mu} \cdot \mu^{11}$
识别分布形式：
$p(\mu \mid Y) \propto \mu^{11} \cdot e^{-5\mu}$
对比 $\text{Gamma}(\alpha, \beta)$ 的核 $\mu^{\alpha-1} e^{-\beta\mu}$：
$\alpha - 1 = 11 \Rightarrow \alpha = 12$，$\beta = 5$

后验：$\mu \mid Y \sim \boxed{\text{Gamma}(12,\ 5)}$

后验均值：$E[\mu \mid Y] = 12/5 = 2.4$（即样本均值 $\bar{y} = 2.2$ 附近）

⚠️ 与 Q7（Gamma(1,1) 先验）的后验 Gamma(12,6) 对比：均匀先验的后验 Gamma(12,5) 的均值 2.4 > 2.0，因为均匀先验相当于 Gamma(1,0)，"先验拉力"更小。

Q10 计算题 进阶 考点 11: 二项-贝塔共轭

（Problem Sheet Q3a）从总体中抽取 $n=145$ 个样本，有 12 次成功。数据服从 $\text{Binomial}(145, \theta)$，$\sum y_i = 12$。先验 $\theta \sim \text{Beta}(1, 4)$。求后验。

显示答案与解析 ▼
共轭公式：先验 $\text{Beta}(\alpha, \beta)$ + 二项数据 → 后验 $\text{Beta}(\alpha + \sum y_i,\ \beta + n - \sum y_i)$
代入：
$\alpha' = 1 + 12 = 13$
$\beta' = 4 + 145 - 12 = 137$

后验：$\theta \mid Y \sim \boxed{\text{Beta}(13,\ 137)}$

后验均值：$E[\theta \mid Y] = \frac{13}{13+137} = \frac{13}{150} \approx 0.0867$

（对比 MLE：$\hat{\theta} = 12/145 \approx 0.0828$，先验 Beta(1,4) 的均值为 $1/5=0.2$，后验被大量数据拉向 MLE。）

Q11 计算题 综合 考点 5（二项版）: 离散先验

（Problem Sheet Q3b）同 Q10 数据，但先验改为离散：$\theta \in \{0.5, 0.8\}$，各概率 0.5。求后验。

显示答案与解析 ▼
Step 1：二项似然
$L(\theta \mid Y) \propto \theta^{12} (1-\theta)^{133}$
（$\binom{145}{12}$ 对两个 $\theta$ 都一样，约分掉）
Step 2：用对数比较
由于数值极小，用对数计算：
$\ln L(0.5) = 12\ln(0.5) + 133\ln(0.5) = 145\ln(0.5) \approx -100.5$
$\ln L(0.8) = 12\ln(0.8) + 133\ln(0.2) \approx -2.68 + (-214.05) = -216.73$

$\ln L(0.5) - \ln L(0.8) \approx 116.2$
即 $L(0.5) / L(0.8) \approx e^{116} \gg 1$
Step 3：结论
$\theta = 0.5$ 的似然远远大于 $\theta = 0.8$，因此：
$p(\theta = 0.5 \mid Y) \approx \boxed{1.0000}$
$p(\theta = 0.8 \mid Y) \approx \boxed{0.0000}$

解读：12/145 ≈ 0.083，这个成功率离 0.5 和 0.8 都很远，但 0.5 产生如此低成功率的概率虽然极小，仍比 0.8 产生 12/145 的概率大得多（差了 $e^{116}$ 倍）。

Q12 简答题 基础 考点 9: 数据量影响

用课件中的例子说明：当数据量从 1 增加到多个时，后验分布发生了什么变化？为什么会这样？

显示答案与解析 ▼

参考答案：

在课件例题中，仅使用单个观测 $Y_1 = 3.2$ 时，$p(\mu=2 \mid Y_1) = 0.1238$，各 $\mu$ 值的后验概率相对分散。

使用 4 个观测后（$\bar{y} = 3.275$），$p(\mu=2 \mid Y) = 0.0157$，后验概率集中在 $\mu = 3.0$ 和 $3.5$ 上。

原因：

（1）联合似然中指数的系数从 $\frac{1}{2\sigma_0^2}$ 变为 $\frac{n}{2\sigma_0^2}$，$n$ 越大，似然函数越"尖"，区分力越强。

（2）更多数据提供了关于 $\mu$ 的更多信息，后验越来越由数据（似然）主导，先验的影响相对减弱。

Q13 选择题 进阶 考点 6: 似然公式细节

若 $Y_1, \ldots, Y_{10} \sim N(\mu, \sigma_0^2 = 4)$，$\bar{y} = 7.5$。联合似然中指数部分是？

  • A. $e^{-\frac{10}{8}(7.5 - \mu)^2}$
  • B. $e^{-\frac{1}{8}(7.5 - \mu)^2}$
  • C. $e^{-\frac{10}{4}(7.5 - \mu)^2}$
  • D. $e^{-\frac{1}{2}(7.5 - \mu)^2}$
显示答案与解析 ▼

正确答案：A

解析：$L(\mu \mid Y) \propto e^{-\frac{n}{2\sigma_0^2}(\bar{y}-\mu)^2}$。代入 $n=10$，$\sigma_0^2=4$：
指数 $= -\frac{10}{2 \times 4}(7.5 - \mu)^2 = -\frac{10}{8}(7.5 - \mu)^2$。
选项 B 少了 $n$；C 分母只有 $\sigma_0^2$ 没乘 2；D 忽略了 $n$ 和 $\sigma_0^2$。

Q14 简答题 进阶 考点 3, 5: 先验选择

在正态数据贝叶斯推断中，如果将离散均匀先验改为非均匀先验（例如给某个 $\mu_j$ 更高的先验概率），后验会如何变化？请用贝叶斯公式解释。

显示答案与解析 ▼

参考答案：

后验公式为 $p(\mu_j \mid Y) = \frac{p(Y \mid \mu_j) \cdot p(\mu_j)}{\sum_i p(Y \mid \mu_i) \cdot p(\mu_i)}$。

如果给 $\mu_j$ 更高的先验 $p(\mu_j)$，则分子中 $p(\mu_j)$ 增大，对应的后验概率也会增大（假设似然不变）。这意味着：

（1）先验概率高的值在后验中也会获得"加成"。

（2）但当数据量足够大时，似然函数的差异会主导后验，先验的影响变小。

（3）当数据量很小时，先验对后验的影响很显著。

这体现了贝叶斯推断的本质：后验 = 先验信念 + 数据证据的综合。

Q15 计算题 综合 考点 4, 5, 6, 7 综合

设 $Y_1, Y_2, Y_3 \sim N(\mu, \sigma_0^2 = 1)$，观测到 $y_1 = 5.1$，$y_2 = 4.7$，$y_3 = 5.4$。$\mu \in \{4, 5, 6\}$，先验为 $p(\mu=4) = 0.2$，$p(\mu=5) = 0.5$，$p(\mu=6) = 0.3$。求后验分布。

显示答案与解析 ▼
Step 1：样本均值
$\bar{y} = \frac{5.1 + 4.7 + 5.4}{3} = \frac{15.2}{3} \approx 5.0667$
Step 2：似然参数
$\frac{n}{2\sigma_0^2} = \frac{3}{2 \times 1} = 1.5$
$L(\mu \mid Y) \propto e^{-1.5(\bar{y} - \mu)^2}$
Step 3：各 $\mu$ 的似然
$\mu=4$：$e^{-1.5(5.0667-4)^2} = e^{-1.5 \times 1.1378} = e^{-1.7067} \approx 0.1816$
$\mu=5$：$e^{-1.5(5.0667-5)^2} = e^{-1.5 \times 0.004444} = e^{-0.006667} \approx 0.9934$
$\mu=6$：$e^{-1.5(5.0667-6)^2} = e^{-1.5 \times 0.8711} = e^{-1.3067} \approx 0.2709$
Step 4：先验 × 似然
$\mu=4$：$0.2 \times 0.1816 = 0.03632$
$\mu=5$：$0.5 \times 0.9934 = 0.49670$
$\mu=6$：$0.3 \times 0.2709 = 0.08127$
求和：$0.6143$
Step 5：后验
$p(\mu=4 \mid Y) = \frac{0.03632}{0.6143} \approx \boxed{0.0591}$

$p(\mu=5 \mid Y) = \frac{0.49670}{0.6143} \approx \boxed{0.8086}$

$p(\mu=6 \mid Y) = \frac{0.08127}{0.6143} \approx \boxed{0.1323}$

验证：$0.0591 + 0.8086 + 0.1323 = 1.0000$ ✓

解读：$\bar{y} \approx 5.07$ 非常接近 $\mu = 5$，且先验本身就给了 $\mu=5$ 最高权重（0.5），因此后验高度集中于 $\mu = 5$（约 81%）。
