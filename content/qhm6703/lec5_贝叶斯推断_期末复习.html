📖 第一部分：课程内容讲解

🗺️ 整体知识脉络

本讲的核心问题是：当我们观测到的数据是离散的（如"是/否"、"次数"）时，如何用贝叶斯方法来估计未知的总体参数？

整体逻辑分为两条平行主线，结构完全对称：

主线一：二项数据（Binomial Data）
观测数据是"成功/失败"型 → 未知参数是"成功比例 \(\pi\)" → 选 Beta 先验 → 得到 Beta 后验
主线二：泊松数据（Poisson Data）
观测数据是"计数"型 → 未知参数是"平均发生率 \(\mu\)" → 选 Gamma 先验 → 得到 Gamma 后验
把贝叶斯推断想象成"更新信念"的过程：你有一个初始猜测（先验），看到新数据后（似然），你的猜测被更新（后验）。就像天气预报员根据卫星云图不断修正降雨概率一样。

🔑 贝叶斯推断的通用框架

不论数据类型如何，贝叶斯推断都遵循相同的四步流程：

第一步：确定未知参数（Parameter）

我们想估计的总体特征。例如"人群中感到幸福的比例 \(\omega\)"或"平均索赔次数 \(\mu\)"。

第二步：选择先验分布（Prior Distribution）

在看到数据之前，我们对参数的初始信念。可以是无信息的（如均匀分布），也可以包含既有知识。

第三步：构建似然函数（Likelihood Function）

给定参数值，观测到当前数据的概率。它把数据和参数联系起来。

第四步：计算后验分布（Posterior Distribution）

通过贝叶斯公式，将先验与似然结合：

\[ p(\theta \mid \text{data}) = \frac{p(\text{data} \mid \theta) \cdot p(\theta)}{p(\text{data})} \propto p(\text{data} \mid \theta) \cdot p(\theta) \]
后验 ∝ 似然 × 先验。"先验"是你进考场前的复习程度，"似然"是考题给的信息量，"后验"就是你答题时真正的把握度——两者缺一不可。

📊 主线一：二项数据 + Beta 先验

1. 问题背景（Happiness 例子）

调查 129 名 65 岁以上城市女性是否感到幸福。每个人的回答 \(Y_i \in \{0, 1\}\)，总共有 118 人回答"幸福"。我们想估计总体中幸福的比例 \(\omega\)。

2. 数据分布

每个人的回答独立且同分布：

\[ Y_1, Y_2, \ldots, Y_n \mid \omega \stackrel{i.i.d.}{\sim} \text{Bernoulli}(\omega) = \text{Binomial}(1, \omega) \]

3. 先验分布

如果我们对 \(\omega\) 没有任何先验知识，选择均匀分布：

\[ \omega \sim U(0,1) = \text{Beta}(1,1), \quad p(\omega) = 1 \text{ for } \omega \in [0,1] \]

更一般地，我们可以选择任意 Beta 先验：\(\omega \sim \text{Beta}(a, b)\)。

4. 似然函数

\[ p(y_1, \ldots, y_n \mid \omega) = \prod_{i=1}^{n} \omega^{y_i}(1-\omega)^{1-y_i} = \omega^{\sum y_i}(1-\omega)^{n - \sum y_i} \]

5. 后验分布（核心结论）

Beta-Binomial 共轭结果：
若先验 \(\omega \sim \text{Beta}(a, b)\)，数据 \(Y_1, \ldots, Y_n \mid \omega \stackrel{i.i.d.}{\sim} \text{Bin}(1, \omega)\)，设 \(y = \sum_{i=1}^{n} y_i\)，则

\[ \omega \mid Y_1, \ldots, Y_n \sim \text{Beta}(a + y, \; b + n - y) \]

直观理解：先验参数 \(a\) 加上"成功次数" \(y\)，\(b\) 加上"失败次数" \(n - y\)。数据就像投票一样，把证据叠加到你原来的信念上。

6. 后验估计（以 Happiness 例子为例）

数据：\(n = 129\), \(y = 118\)，先验 \(\text{Beta}(1,1)\)，后验 \(\text{Beta}(119, 12)\)。

位置度量（均值）：
先验均值 = \(\frac{1}{2} = 0.5\)，样本均值 = \(\frac{118}{129} = 0.915\)，后验均值 = \(\frac{119}{131} = 0.908\)

离散度量（方差）：
先验方差 = \(0.083\)，后验方差 = \(0.0006\)（大幅缩小，说明数据提供了很多信息）

📈 主线二：泊松数据 + Gamma 先验

1. 问题背景（Birth Rates 例子）

调查 155 名 40 岁以上女性的生育子女数。按是否有大学学位分组：无学位 \(n_1 = 111\) 人，有学位 \(n_2 = 44\) 人。我们想估计两组的平均生育数 \(\omega_1, \omega_2\)。

2. 为什么不能用 Beta 先验？

Beta 分布的取值范围是 \([0, 1]\)，而平均生育数 \(\omega \in [0, +\infty)\)，所以不能用 Beta 先验。需要一个支撑在 \([0, +\infty)\) 上的分布 → Gamma 分布。

3. 数据分布

\[ X_1, \ldots, X_{n_1} \mid \omega_1 \stackrel{i.i.d.}{\sim} \text{Poisson}(\omega_1) \]

4. 先验分布

\[ \omega \sim \text{Gamma}(a, b), \quad p(\omega) = \frac{b^a}{\Gamma(a)} \omega^{a-1} e^{-b\omega}, \quad \omega \geq 0 \]

5. 似然函数

\[ p(x_1, \ldots, x_n \mid \omega) = \prod_{i=1}^{n} \frac{\omega^{x_i} e^{-\omega}}{x_i!} = c(x_1,\ldots,x_n) \cdot \omega^{\sum x_i} e^{-n\omega} \]

6. 后验分布（核心结论）

Gamma-Poisson 共轭结果：
若先验 \(\omega \sim \text{Gamma}(a, b)\)，数据 \(X_1, \ldots, X_n \mid \omega \stackrel{i.i.d.}{\sim} \text{Poisson}(\omega)\)，则

\[ \omega \mid X_1, \ldots, X_n \sim \text{Gamma}\!\left(a + \sum_{i=1}^{n} x_i, \; b + n\right) \]

直观理解：先验参数 \(a\) 加上"观测总数" \(\sum x_i\)，\(b\) 加上"样本量" \(n\)。

7. 后验估计（以 Birth Rates 例子为例）

先验：\(\omega_1, \omega_2 \sim \text{Gamma}(2, 1)\)。

数据：\(\sum x_i = 217, n_1 = 111\)；\(\sum y_i = 66, n_2 = 44\)。

后验： \(\omega_1 \mid X \sim \text{Gamma}(219, 112)\)，\(\omega_2 \mid Y \sim \text{Gamma}(68, 45)\)

位置度量： 先验均值 = 2，后验均值：\(E[\omega_1|X] = 219/112 = 1.955\)，\(E[\omega_2|Y] = 68/45 = 1.51\)

离散度量： 先验方差 = 2，后验方差：\(\text{Var}[\omega_1|X] = 219/112^2 = 0.017\)，\(\text{Var}[\omega_2|Y] = 68/45^2 = 0.033\)

🔗 共轭先验（Conjugate Prior）

本讲的两个案例展示了一个重要模式——共轭性：

当先验分布和后验分布属于同一分布族时，该先验称为该似然的共轭先验。

Beta 是 Binomial 的共轭先验 → 后验仍是 Beta
Gamma 是 Poisson 的共轭先验 → 后验仍是 Gamma
共轭先验就像"兼容的积木"——先验和似然拼在一起，后验的形状和先验一样，只是参数更新了。这让计算变得非常方便。

🎯 第二部分：考点梳理
★★★
考点 1：贝叶斯推断基本框架
需要理解

定义：贝叶斯公式 \(p(\theta \mid \text{data}) \propto p(\text{data} \mid \theta) \cdot p(\theta)\)，即后验 ∝ 似然 × 先验。

关键公式：\(p(\theta \mid y) = \frac{p(y \mid \theta) \, p(\theta)}{p(y)}\)，其中 \(p(y) = \int p(y|\theta)p(\theta)\,d\theta\) 是边际分布（归一化常数）。

后验分布的"形状"由似然×先验决定，\(p(y)\) 只是一个与 \(\theta\) 无关的归一化常数。不需要计算 \(p(y)\) 也能识别后验分布的类型。
★★★
考点 2：Beta-Binomial 共轭模型
需要计算 需要记忆

设置：数据 \(Y_1,\ldots,Y_n | \pi \stackrel{i.i.d.}{\sim} \text{Bin}(1,\pi)\)，先验 \(\pi \sim \text{Beta}(a,b)\)。

核心公式：

\[ \pi \mid Y_1,\ldots,Y_n \sim \text{Beta}(a + y, \; b + n - y), \quad y = \sum_{i=1}^{n} y_i \]

特殊情况：均匀先验 \(U(0,1) = \text{Beta}(1,1)\)，后验为 \(\text{Beta}(1+y, 1+n-y)\)。

注意 \(a\) 加的是成功次数 \(y\)，\(b\) 加的是失败次数 \(n-y\)，不要搞反！另外 \(U(0,1)\) 就是 \(\text{Beta}(1,1)\)，不是 \(\text{Beta}(0,0)\)。
★★★
考点 3：Gamma-Poisson 共轭模型
需要计算 需要记忆

设置：数据 \(X_1,\ldots,X_n | \mu \stackrel{i.i.d.}{\sim} \text{Poisson}(\mu)\)，先验 \(\mu \sim \text{Gamma}(a,b)\)。

核心公式：

\[ \mu \mid X_1,\ldots,X_n \sim \text{Gamma}\!\left(a + \sum_{i=1}^{n} x_i, \; b + n\right) \]
Gamma 的第一个参数加的是"观测总数" \(\sum x_i\)（不是样本量！），第二个参数加的才是样本量 \(n\)。这与 Beta 的更新逻辑不同。
★★★
考点 4：Beta 分布的均值与方差
需要记忆 需要计算

公式：若 \(X \sim \text{Beta}(a,b)\)，则

\[ E[X] = \frac{a}{a+b}, \qquad \text{Var}[X] = \frac{ab}{(a+b)^2(a+b+1)} \]
方差公式的分母有两个因子：\((a+b)^2\) 和 \((a+b+1)\)。不要遗漏 \((a+b+1)\)。
★★★
考点 5：Gamma 分布的均值与方差
需要记忆 需要计算

公式：若 \(X \sim \text{Gamma}(a,b)\)（rate parameterization），则

\[ E[X] = \frac{a}{b}, \qquad \text{Var}[X] = \frac{a}{b^2} \]
Gamma 分布有两种参数化方式（rate vs. scale）。本课使用 rate 参数化：\(\text{Gamma}(a, b)\) 中 \(b\) 是 rate。均值 = shape/rate，方差 = shape/rate²。
★★
考点 6：先验、样本均值与后验均值的比较
需要理解 需要计算

核心理解：后验均值通常介于先验均值和样本均值之间——是两者的"加权折中"。数据量越大，后验越靠近样本均值；数据量越小，先验影响越大。

后验方差始终小于先验方差——数据总是减少不确定性。

★★
考点 7：共轭先验的概念
需要理解 需要记忆

定义：若先验分布和后验分布属于同一分布族，则该先验称为该似然的共轭先验。

本讲的两对共轭：Beta ↔ Binomial，Gamma ↔ Poisson。

★★
考点 8：Gamma 先验的参数匹配（矩匹配法）
需要计算

方法：已知先验均值 \(m\) 和标准差 \(s\)，求 \(\text{Gamma}(r, w)\) 的参数：

\[ \frac{r}{w} = m, \quad \frac{r}{w^2} = s^2 \implies w = \frac{m}{s^2}, \quad r = \frac{m^2}{s^2} \]
注意用的是方差 \(s^2\)，不是标准差 \(s\)。题目往往给标准差，需要先平方。
★★
考点 9：似然函数的推导
需要理解 需要计算

要点：独立同分布数据的似然 = 各单个观测概率之积。对于 Binomial 和 Poisson 似然，要能从头推导出来。

关键技巧：似然作为参数的函数，可以忽略与参数无关的常数因子（如 \(\binom{n}{y}\) 或 \(x_i!\)），只保留与 \(\theta\) 有关的部分。

★
考点 10：边际分布 \(p(y)\) 的计算
需要理解 需要计算

公式：\(p(y) = \int p(y|\theta)p(\theta)\,d\theta\)，利用已知分布的归一化常数来计算。

技巧：通过识别积分核（kernel）与 Beta/Gamma 函数的关系：\(\int_0^1 x^{a-1}(1-x)^{b-1}dx = \frac{\Gamma(a)\Gamma(b)}{\Gamma(a+b)}\)。

★
考点 11：非共轭先验的后验推导
需要计算 需要理解

要点：当先验不是共轭先验时，后验不一定属于已知分布族。需要手动推导后验密度，可能需要数值积分来归一化。

方法：后验 \(\propto\) 似然 × 先验。展开、化简，看是否能识别为已知分布的核。

对应题目：Problem Sheet 第 5 题。

✏️ 第三部分：复习题目
选择题 考点 7：共轭先验 基础
以下哪对是共轭先验-似然配对？
  • A. Gamma 先验 + Binomial 似然
  • B. Beta 先验 + Binomial 似然
  • C. Beta 先验 + Poisson 似然
  • D. Normal 先验 + Binomial 似然
显示答案与解析
答案：B

解析：Beta 是 Binomial 的共轭先验（后验仍为 Beta）。Gamma 是 Poisson 的共轭先验。A、C、D 都不构成共轭对。

考查点：记住两对共轭关系：Beta↔Binomial，Gamma↔Poisson。
选择题 考点 2：Beta-Binomial 基础
均匀先验 \(U(0,1)\) 等价于哪个 Beta 分布？
  • A. Beta(0, 0)
  • B. Beta(0.5, 0.5)
  • C. Beta(1, 1)
  • D. Beta(2, 2)
显示答案与解析
答案：C

解析：将 \(a=1, b=1\) 代入 Beta PDF：\(p(\theta) = \frac{\Gamma(2)}{\Gamma(1)\Gamma(1)} \theta^{0}(1-\theta)^{0} = 1\)，恰好是 \([0,1]\) 上的均匀分布。

易错提醒：Beta(0,0) 不是合法的分布参数（\(a, b > 0\)）。Beta(0.5, 0.5) 是 Jeffreys 先验，不是均匀先验。
判断题 考点 6：先验与后验比较 基础
判断：后验方差总是小于先验方差。
显示答案与解析
答案：正确

解析：在共轭模型中，数据总是增加后验分布的参数总和（\(a+b\) 或 \(a+b\) 都增大），从而减小方差。直观理解：看到更多数据后，我们对参数的不确定性降低了。

考查点：理解数据如何"收紧"后验分布。
选择题 考点 3：Gamma-Poisson 进阶
若先验 \(\mu \sim \text{Gamma}(3, 1)\)，观测到 \(n=5\) 个独立 Poisson 数据的总和为 \(\sum x_i = 20\)，后验分布是？
  • A. Gamma(20, 5)
  • B. Gamma(23, 5)
  • C. Gamma(20, 6)
  • D. Gamma(23, 6)
显示答案与解析
答案：D

解题步骤：
后验 = \(\text{Gamma}(a + \sum x_i, \; b + n)\)
= \(\text{Gamma}(3 + 20, \; 1 + 5)\)
= \(\text{Gamma}(23, 6)\)
易错提醒：第一个参数加的是观测总数 \(\sum x_i = 20\)，不是样本量。第二个参数加的是样本量 \(n = 5\)。
计算题 考点 2：Beta-Binomial 基础
（Problem Sheet Q1）为了确定一本杂志在目标受众中的覆盖效果，一家市场调研公司从目标受众中随机抽取了 150 人进行访谈，其中 29 人看过了最新一期。
(a) 写出 \(Y\)（看过最新一期的人数）的分布。
(b) 使用 \(\pi\) 的均匀先验，求 \(\pi\) 的后验分布。
(c) 比较先验均值和方差与后验均值和方差。
显示答案与解析
(a) 数据分布：
每个人独立地以概率 \(\pi\) 看过杂志，\(n=150\) 人中有 \(Y\) 人看过。
\[ Y \mid \pi \sim \text{Binomial}(150, \pi) \]
(b) 后验分布：
先验：\(\pi \sim U(0,1) = \text{Beta}(1, 1)\)
数据：\(y = 29, \; n = 150\)
由 Beta-Binomial 共轭：
\[ \pi \mid Y \sim \text{Beta}(1 + 29, \; 1 + 150 - 29) = \text{Beta}(30, 122) \]
(c) 先验 vs 后验的均值和方差：

先验 \(\text{Beta}(1,1)\)：
均值 = \(\frac{1}{1+1} = 0.5\)
方差 = \(\frac{1 \times 1}{(1+1)^2(1+1+1)} = \frac{1}{12} \approx 0.0833\)

后验 \(\text{Beta}(30, 122)\)：
均值 = \(\frac{30}{30+122} = \frac{30}{152} \approx 0.1974\)
方差 = \(\frac{30 \times 122}{(152)^2 \times 153} = \frac{3660}{3,535,296} \approx 0.001035\)

结论：后验均值（0.197）远离先验均值（0.5），靠近样本均值（29/150 ≈ 0.193）。后验方差（0.001）远小于先验方差（0.083），说明数据大大减少了不确定性。
计算题 考点 2：Beta-Binomial 基础
（Problem Sheet Q2）一座城市考虑建造一座新博物馆。当地报纸对 120 名居民进行了民调，其中 74 人支持建馆。
(a) 写出 \(Y\) 的分布。
(b) 使用均匀先验，求 \(\pi\) 的后验分布。
(c) 比较先验和后验的均值与方差。
显示答案与解析
(a) 数据分布：
\[ Y \mid \pi \sim \text{Binomial}(120, \pi) \]
(b) 后验分布：
先验：\(\pi \sim \text{Beta}(1, 1)\)，数据：\(y = 74, \; n = 120\)
\[ \pi \mid Y \sim \text{Beta}(1 + 74, \; 1 + 120 - 74) = \text{Beta}(75, 47) \]
(c) 先验 vs 后验比较：

先验 Beta(1,1)： 均值 = 0.5，方差 = 1/12 ≈ 0.0833

后验 Beta(75, 47)：
均值 = \(\frac{75}{75+47} = \frac{75}{122} \approx 0.6148\)
方差 = \(\frac{75 \times 47}{(122)^2 \times 123} = \frac{3525}{1,830,852} \approx 0.001925\)

样本均值 = 74/120 ≈ 0.617。后验均值 0.615 非常接近样本均值，后验方差大幅缩小。
计算题 考点 3：Gamma-Poisson 进阶
（Problem Sheet Q3）保险公司每周收到的索赔数服从 \(\text{Poisson}(\mu)\)。十周内观测到的索赔数为：5, 8, 4, 6, 11, 6, 6, 5, 6, 4。先验为 \(\mu \sim \text{Gamma}(1, 2)\)。
(a) 求 \(\mu\) 的后验分布。
(b) 求后验均值和方差。
显示答案与解析
(a) 后验分布：
先验：\(\mu \sim \text{Gamma}(1, 2)\)，即 \(a = 1, b = 2\)
样本量：\(n = 10\)
观测总数：\(\sum x_i = 5+8+4+6+11+6+6+5+6+4 = 61\)

由 Gamma-Poisson 共轭：
\[ \mu \mid X \sim \text{Gamma}(1 + 61, \; 2 + 10) = \text{Gamma}(62, 12) \]
(b) 后验均值和方差：
后验均值 = \(\frac{a'}{b'} = \frac{62}{12} \approx 5.167\)

后验方差 = \(\frac{a'}{b'^2} = \frac{62}{144} \approx 0.431\)

对比：先验均值 = 1/2 = 0.5，先验方差 = 1/4 = 0.25。样本均值 = 61/10 = 6.1。后验均值 5.167 在先验均值（0.5）和样本均值（6.1）之间，但由于数据量大，更接近样本均值。
计算题 考点 8：矩匹配 + 考点 3 进阶
（Problem Sheet Q4）织布机每 10 米布的缺陷数服从 \(\text{Poisson}(\lambda)\)。你检查了 100 米布，发现 71 个缺陷。
(a) 你的先验信念是 \(\lambda\) 的均值为 6，标准差为 2。求匹配的 \(\text{Gamma}(r, w)\) 先验参数。
(b) 求观测到 71 个缺陷后 \(\lambda\) 的后验分布。
显示答案与解析
(a) 矩匹配求先验参数：
已知 \(E[\lambda] = r/w = 6\)，\(\text{SD}[\lambda] = 2 \Rightarrow \text{Var}[\lambda] = r/w^2 = 4\)

由 \(\frac{r/w}{r/w^2} = \frac{6}{4}\) 得 \(w = \frac{6}{4} = 1.5\)

代入 \(r/w = 6\) 得 \(r = 6 \times 1.5 = 9\)

先验：\(\lambda \sim \text{Gamma}(9, 1.5)\)
(b) 后验分布：
100 米布 = 10 个"每 10 米"单元，所以 \(n = 10\)

计算题 考点 11：非共轭先验 综合
（Problem Sheet Q5）我们对 \(\text{Binomial}(n, \theta)\) 分布的参数 \(\theta\) 感兴趣。\(\theta\) 的先验密度为： \[ f(\theta) = k_0 \left[\theta^2(1-\theta) + \theta(1-\theta)^2\right], \quad 0 < \theta < 1 \] 这不是共轭先验。

(a)(i) 求 \(k_0\) 的值。
(a)(ii) 求 \(\theta\) 的先验均值。
(a)(iii) 求 \(\theta\) 的先验标准差。
(b)(i) 写出似然函数。
(b)(ii) 求 \(\theta\) 的后验密度。
(b)(iii) 求 \(\theta\) 的后验均值。
显示答案与解析
(a)(i) 求 \(k_0\)：
先化简先验核：
\(\theta^2(1-\theta) + \theta(1-\theta)^2\)
\(= \theta^2 - \theta^3 + \theta(1 - 2\theta + \theta^2)\)
\(= \theta^2 - \theta^3 + \theta - 2\theta^2 + \theta^3\)
\(= \theta - \theta^2\)
\(= \theta(1-\theta)\)

因此 \(f(\theta) = k_0 \cdot \theta(1-\theta)\)。归一化：
\(\int_0^1 k_0 \theta(1-\theta)\,d\theta = k_0 \left[\frac{\theta^2}{2} - \frac{\theta^3}{3}\right]_0^1 = k_0 \cdot \frac{1}{6} = 1\)

\[\boxed{k_0 = 6}\]
(a)(ii) 先验均值：
\(E[\theta] = \int_0^1 \theta \cdot 6\theta(1-\theta)\,d\theta = 6\int_0^1 (\theta^2 - \theta^3)\,d\theta\)
\(= 6\left[\frac{1}{3} - \frac{1}{4}\right] = 6 \times \frac{1}{12}\)

\[\boxed{E[\theta] = \frac{1}{2}}\]
(a)(iii) 先验标准差：
\(E[\theta^2] = \int_0^1 \theta^2 \cdot 6\theta(1-\theta)\,d\theta = 6\int_0^1 (\theta^3 - \theta^4)\,d\theta = 6\left[\frac{1}{4} - \frac{1}{5}\right] = 6 \times \frac{1}{20} = \frac{3}{10}\)

\(\text{Var}[\theta] = \frac{3}{10} - \left(\frac{1}{2}\right)^2 = \frac{3}{10} - \frac{1}{4} = \frac{12 - 10}{40} = \frac{1}{20}\)

\[\boxed{\text{SD}[\theta] = \sqrt{\frac{1}{20}} = \frac{1}{2\sqrt{5}} \approx 0.2236}\]
(b)(i) 似然函数：
观测到 \(X = x\)，其中 \(X \sim \text{Binomial}(n, \theta)\)：
\[L(\theta \mid x) = \binom{n}{x} \theta^x (1-\theta)^{n-x} \propto \theta^x(1-\theta)^{n-x}\]
(b)(ii) 后验密度：
\(f(\theta \mid x) \propto L(\theta \mid x) \cdot f(\theta)\)
\(= \theta^x(1-\theta)^{n-x} \cdot 6\theta(1-\theta)\)
\(= 6\,\theta^{x+1}(1-\theta)^{n-x+1}\)

这是 \(\text{Beta}(x+2, \; n-x+2)\) 分布的核！归一化后：
\[\boxed{f(\theta \mid x) = \frac{\Gamma(n+4)}{\Gamma(x+2)\,\Gamma(n-x+2)} \theta^{x+1}(1-\theta)^{n-x+1}}\] 即 \(\theta \mid X = x \sim \text{Beta}(x+2, \; n-x+2)\)。
(b)(iii) 后验均值：
由 Beta 分布均值公式：
\[\boxed{E[\theta \mid x] = \frac{x+2}{n+4}}\]
有趣的发现：虽然先验不是标准 Beta 分布，但化简后 \(f(\theta) \propto \theta(1-\theta)\)，其实等价于 \(\text{Beta}(2,2)\)。所以后验仍然是 Beta 分布！

计算题 考点 2 + 4 + 6 综合 综合
某医院想估计一种新疫苗的有效率 \(\pi\)。根据前期试验，医生认为 \(\pi\) 服从 \(\text{Beta}(3, 1)\) 先验。随后对 200 名受试者进行试验，其中 170 人产生了有效免疫反应。
(a) 求 \(\pi\) 的后验分布。
(b) 求先验和后验的均值、方差。
(c) 与样本比例相比，后验均值偏向哪一侧？解释原因。
显示答案与解析
(a) 后验分布：
先验：\(\pi \sim \text{Beta}(3, 1)\)，\(y = 170, n = 200\)
\[\pi \mid Y \sim \text{Beta}(3 + 170, \; 1 + 200 - 170) = \text{Beta}(173, 31)\]
(b) 均值和方差：
先验 Beta(3,1)：
均值 = \(3/4 = 0.75\)
方差 = \(\frac{3 \times 1}{16 \times 5} = \frac{3}{80} = 0.0375\)

后验 Beta(173, 31)：
均值 = \(\frac{173}{204} \approx 0.848\)
方差 = \(\frac{173 \times 31}{(204)^2 \times 205} = \frac{5363}{8,528,880} \approx 0.000629\)
(c) 分析：
样本比例 = \(170/200 = 0.85\)。后验均值 0.848 非常接近样本比例 0.85，略偏向先验均值 0.75 的方向。

原因：数据量很大（\(n=200\)），先验的"权重"相对较小（先验可以理解为"虚拟的 \(a+b-2 = 2\) 个观测"），所以后验几乎完全由数据主导。先验的拉力效应非常微弱。
简答题 考点 1 + 7：贝叶斯框架 + 共轭 进阶
(a) 解释为什么在贝叶斯推断中，我们说"后验正比于似然乘以先验"，而不需要直接计算 \(p(\text{data})\)。
(b) 什么是共轭先验？使用共轭先验有什么优势？
显示答案与解析
(a)
贝叶斯公式为 \(p(\theta|y) = \frac{p(y|\theta)p(\theta)}{p(y)}\)。分母 \(p(y) = \int p(y|\theta)p(\theta)\,d\theta\) 是一个积分常数，不依赖于参数 \(\theta\)。因此在确定后验分布的"形状"时，我们只需关注分子 \(p(y|\theta) \cdot p(\theta)\)，即后验 \(\propto\) 似然 × 先验。

一旦识别出后验核（kernel）属于哪个已知分布族，就可以直接写出归一化常数，无需手动计算 \(p(y)\)。
(b)
共轭先验是指：如果选择某一先验分布族后，得到的后验分布仍然属于同一个分布族，则该先验称为该似然的共轭先验。

优势：使用共轭先验使得后验分布有封闭形式（closed-form），可以直接写出后验的参数，无需数值积分或模拟方法，计算简便高效。
